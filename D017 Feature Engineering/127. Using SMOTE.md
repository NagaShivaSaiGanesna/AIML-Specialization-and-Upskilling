# Feature Engineering: SMOTE (Synthetic Minority Over-sampling Technique)

In previous discussions, we explored basic **Upsampling** (duplication) and **Downsampling** (deletion). While standard upsampling helps balance classes, it lacks **variance** because it simply repeats existing data points. **SMOTE** is a more sophisticated upsampling technique that generates **synthetic** instances to populate the minority class effectively.

---

## 1. What is SMOTE?

**SMOTE** stands for **Synthetic Minority Over-sampling Technique**. Instead of duplicating existing rows, SMOTE creates new, unique data points by **interpolating** between existing minority instances.

### The Intuition: Interpolation vs. Duplication

* **Standard Upsampling:** Adds data points exactly on top of existing ones. The model sees the same information repeatedly.
* **SMOTE:** Joins a minority point with its nearest neighbors and creates new points along the lines connecting them. This introduces new "synthetic" information and increases the statistical variance of the minority class.

---

## 2. How SMOTE Works (Step-by-Step)

1. **Select a Point:** The algorithm picks a random instance from the minority class.
2. **Find Neighbors:** It identifies its **k-nearest neighbors** (usually ).
3. **Draw Lines:** It draws a line between the selected point and one of its neighbors.
4. **Synthesize:** A new data point is generated at a random location on that line.

This process continues until the minority class reaches the same count as the majority class.

---

## 3. Implementation in Python

To use SMOTE, we utilize the `imblearn` (Imbalanced-Learn) library. Below is a practical walkthrough.

### Step 1: Create an Imbalanced Dataset

We use `make_classification` to create a dataset where **90%** of data is "Class 0" and **10%** is "Class 1".

```python
from sklearn.datasets import make_classification
import pandas as pd

# Create imbalanced data: 1000 samples, 2 features, 90/10 weight
X, y = make_classification(n_samples=1000, n_features=2, n_redundant=0, 
                           n_clusters_per_class=1, weights=[0.90], random_state=12)

df = pd.DataFrame(X, columns=['f1', 'f2'])
df['target'] = y
print(df['target'].value_counts()) 
# Output: 0: 900, 1: 100

```

### Step 2: Apply SMOTE

We install `imblearn` and apply the `SMOTE` transformation.

```python
# pip install imbalanced-learn
from imblearn.over_sampling import SMOTE

# Initialize SMOTE
oversample = SMOTE()

# Fit and transform the data
X_resampled, y_resampled = oversample.fit_resample(df[['f1', 'f2']], df['target'])

print(pd.Series(y_resampled).value_counts())
# Output: 0: 900, 1: 900

```

## 4. Visualizing the Result

When we plot the data after SMOTE, we see a significant difference in the distribution of the minority class.

| Before SMOTE | After SMOTE |
| --- | --- |
| Minority points are sparse and isolated. | Minority points fill the gaps between original observations. |
| Potential for high bias toward the majority. | Better "decision boundary" for the model to learn. |

---

## 5. Summary Table

| Feature | Standard Upsampling | SMOTE |
| --- | --- | --- |
| **Core Action** | Duplicates existing rows. | Generates new synthetic rows. |
| **Variance** | No change in variance. | Increases variance. |
| **Overfitting Risk** | High (memorization). | Lower (generalization). |
| **Use Case** | Very small datasets. | General imbalanced classification tasks. |

### Conclusion

SMOTE is a powerful tool in your feature engineering toolkit. It allows you to build models that are much more robust at identifying rare events—like credit card fraud or rare medical conditions—without simply "memorizing" the few examples you already have.
