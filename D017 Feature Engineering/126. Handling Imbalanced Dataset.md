# Feature Engineering: Handling Imbalanced Datasets

In supervised machine learning, particularly for **Classification**, you will often encounter datasets where the distribution of labels is not uniform. This is known as an **Imbalanced Dataset**.

---

## 1. What is an Imbalanced Dataset?

An imbalanced dataset occurs when one class (the **Majority Class**) significantly outperforms another class (the **Minority Class**) in terms of the number of observations.

### Example: Binary Classification

Imagine a dataset of **1,000 data points** where the goal is to predict "Yes" or "No":

* **Class Yes:** 900 points (90%)
* **Class No:** 100 points (10%)

### The Problem: Model Bias

If you train a model on this data, it will likely become **biased** toward the majority class. Because the model sees "Yes" 90% of the time, it might simply learn to predict "Yes" for every input to achieve a high accuracy (90%), even though it completely fails to identify the "No" cases. To fix this, we use resampling techniques.

---

## 2. Techniques to Handle Imbalance

There are two primary strategies used to equalize the class distribution: **Upsampling** and **Downsampling**.

| Technique | Action | Result |
| --- | --- | --- |
| **Upsampling** | Increase the number of instances in the **Minority Class**. | More data, but may cause **Overfitting**. |
| **Downsampling** | Decrease the number of instances in the **Majority Class**. | Reduces bias, but results in **Loss of Information**. |

---

## 3. Implementing Upsampling

Upsampling (or Over-sampling) creates artificial or duplicate points for the minority class to match the size of the majority class.

### Workflow:

1. **Segregate** the data into Minority and Majority data frames.
2. Use the `resample` function from `sklearn.utils`.
3. Set `replace=True` to allow the function to duplicate points.
4. Set `n_samples` to equal the length of the Majority class.

### Python Example:

```python
from sklearn.utils import resample

# Upsample minority class
df_minority_upsampled = resample(df_minority, 
                                 replace=True,     # sample with replacement
                                 n_samples=len(df_majority), # match majority class
                                 random_state=42)

# Combine majority class with upsampled minority class
df_upsampled = pd.concat([df_majority, df_minority_upsampled])

```

---

## 4. Implementing Downsampling

Downsampling (or Under-sampling) involves randomly removing observations from the majority class to match the size of the minority class.

### Workflow:

1. **Segregate** the data.
2. Use the `resample` function on the **Majority** class.
3. Set `replace=False` (since we are reducing, not duplicating).
4. Set `n_samples` to equal the length of the Minority class.

### Python Example:

```python
# Downsample majority class
df_majority_downsampled = resample(df_majority, 
                                   replace=False,    # sample without replacement
                                   n_samples=len(df_minority), # match minority class
                                   random_state=42)

# Combine minority class with downsampled majority class
df_downsampled = pd.concat([df_minority, df_majority_downsampled])

```

---

## 5. Summary and Best Practices

* **Upsampling** is generally preferred when you have a small dataset because it prevents you from losing valuable information.
* **Downsampling** is only recommended when you have a massive dataset (e.g., millions of rows) and the reduction doesn't compromise the model's ability to learn.
* **Evaluation Metrics:** When dealing with imbalanced data, never rely solely on **Accuracy**. Instead, use the **F1-Score**, **Precision**, **Recall**, or **AUC-ROC** to measure performance.
