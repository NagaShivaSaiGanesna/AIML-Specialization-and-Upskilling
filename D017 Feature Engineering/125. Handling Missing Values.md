# Feature Engineering: Handling Missing Values

In real-world data science, machine learning, and deep learning projects, data is rarely pristine. You will frequently encounter **messy data** containing **missing values**. Understanding why data is missing and how to handle it is a critical step in the feature engineering pipeline.

---

## 1. Why Data is Missing

Missing values occur when no information is stored for a specific variable in an observation. Common reasons include:

* **User Non-Response:** Survey participants may feel uncomfortable answering sensitive questions (e.g., income or age).
* **Data Entry Errors:** Human error during manual data input.
* **Sensor/Machine Failure:** Technical malfunctions preventing data capture.
* **Data Corruption:** Loss of information during transformation or storage.

---

## 2. Mechanisms of Missing Data

Statisticians categorize missing data into three main frameworks. Understanding these helps determine the best strategy for imputation.

| Mechanism | Definition | Example |
| --- | --- | --- |
| **MCAR** (Missing Completely at Random) | The probability of being missing is unrelated to any data, observed or unobserved. It is essentially a random error. | A data entry operator accidentally skips a row, or a questionnaire page is lost. |
| **MAR** (Missing at Random) | The probability of missingness is related to the **observed data** but not the missing data itself. | Men may be less likely to disclose their salary; the missingness depends on the "Gender" column. |
| **MNAR** (Missing Not at Random) | The missingness depends on the value of the **unobserved data** itself or unmeasured factors. | People with very low job satisfaction might refuse to report their income because of that dissatisfaction. |

---

## 3. Basic Handling: Deletion

Before moving to advanced imputation, we can consider deleting missing data. However, this must be done with caution.

### Row-wise Deletion

Removing every row that contains at least one null value.

* **Pros:** Easy to implement.
* **Cons:** Results in a massive loss of data. In a dataset like Titanic (891 rows), dropping all nulls might leave you with only 182 rows, which is a "blunder" for model training.

### Column-wise Deletion

Removing an entire feature (column) if it contains too many missing values.

* **Use Case:** If a column like **Deck** has 688 missing values out of 891, it may not provide enough signal to be useful.
* **Python Command:** `df.dropna(axis=1)`

---

## 4. Imputation Techniques

Imputation is the process of replacing missing data with substituted values to retain the dataset's size and structure.

### A. Mean Value Imputation

This technique replaces missing values with the **average (mean)** of the available values in that column.

* **Best Used For:** Numerical data that follows a **Normal (Gaussian) Distribution**.
* **Limitation:** It is sensitive to outliers, which can skew the mean.

### B. Median Value Imputation

This replaces missing values with the **middle value (median)** of the column.

* **Best Used For:** Numerical data with **outliers** or skewed distributions (Right-skewed or Left-skewed).
* **Logic:** The median is a robust statistic that is not heavily influenced by extreme values.

### C. Mode Imputation

This replaces missing values with the **most frequent value (mode)** in the column.

* **Best Used For:** **Categorical variables** (e.g., "Embarked Town," "Gender," or "City").
* **Logic:** Since you cannot calculate a mean for words, you use the most common category.

### D. Random Sample Imputation

This involves taking a random observation from the available data in the column and using it to fill the gap.

* **Logic:** It aims to preserve the original distribution of the data better than mean/median imputation.

---

## 5. Implementation in Python (Titanic Dataset)

Using `seaborn` and `pandas`, we can identify and fill missing values efficiently.

### Checking for Nulls

```python
import seaborn as sns
df = sns.load_dataset('titanic')

# Summary of missing values per column
print(df.isnull().sum())

```

### Applying Imputation

To fill the **Age** column with the mean or median:

```python
# Mean Imputation
df['age_mean'] = df['age'].fillna(df['age'].mean())

# Median Imputation
df['age_median'] = df['age'].fillna(df['age'].median())

```

To fill a categorical column like **Embarked** using the mode:

```python
# Calculate the mode (returns a Series, so we take index 0)
mode_val = df['embarked'].mode()[0]

# Mode Imputation
df['embarked_mode'] = df['embarked'].fillna(mode_val)

```
