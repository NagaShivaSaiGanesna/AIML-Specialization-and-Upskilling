# Understanding Type I and Type II Errors

In hypothesis testing, our goal is to make a decision about a population based on sample data. However, because we are using a sample rather than the entire population, there is always a risk of reaching the wrong conclusion. These mistakes are categorized as **Type I** and **Type II** errors.

---

## The Decision Matrix

To understand these errors, we compare the **Reality** (the actual truth about the population) against our **Decision** (the result of our statistical test).

### Outcome 1: Correct Rejection

* **Situation:** The **Null Hypothesis (H0)** is False in reality.
* **Decision:** We reject **H0**.
* **Result:** This is a **Correct Scenario**. We successfully identified that the null hypothesis was wrong.

### Outcome 2: Type I Error (False Positive)

* **Situation:** The **Null Hypothesis (H0)** is True in reality.
* **Decision:** We reject **H0**.
* **Result:** This is an **Error**. We claimed there was an effect or a difference when there actually wasn't one. In statistics, the probability of committing a Type I error is denoted by **alpha**.

### Outcome 3: Type II Error (False Negative)

* **Situation:** The **Null Hypothesis (H0)** is False in reality.
* **Decision:** We fail to reject (retain) **H0**.
* **Result:** This is an **Error**. We failed to detect an effect or a difference that actually exists. The probability of committing a Type II error is denoted by **beta**.

### Outcome 4: Correct Retention

* **Situation:** The **Null Hypothesis (H0)** is True in reality.
* **Decision:** We fail to reject (retain) **H0**.
* **Result:** This is a **Correct Scenario**. We correctly concluded that there wasn't enough evidence to change our mind about the null hypothesis.

---

## Summary Table of Errors

| Reality \ Decision | Fail to Reject H0 (Accept) | Reject H0 |
| --- | --- | --- |
| **H0 is True** | Correct Decision | **Type I Error** (False Positive) |
| **H0 is False** | **Type II Error** (False Negative) | Correct Decision |

---

## Key Terminology

* **Null Hypothesis (H0):** The default assumption that there is no change, no effect, or no difference.
* **Type I Error (Alpha):** Occurs when you see a pattern where none exists. Think of it as a "False Alarm."
* **Type II Error (Beta):** Occurs when you miss a pattern that actually exists. Think of it as a "Failed Detection."
* **Confusion Matrix:** A table often used in Machine Learning to describe the performance of a classification model, which mirrors the logic of Type I and Type II errors (Precision and Recall).

---

## Why This Matters

In fields like medicine or data engineering, the "cost" of these errors differs. For example, a Type I error might mean telling a healthy person they are sick (False Positive), while a Type II error might mean telling a sick person they are healthy (False Negative). Balancing these errors is a fundamental part of being a technical founder or data scientist.
