# Bayesian Statistics and Bayes' Theorem

**Bayesian Statistics** is a method of data analysis and parameter estimation that utilizes **Bayes' Theorem**. Unlike classical statistics, which treats parameters as fixed constants, the Bayesian approach updates the probability of a hypothesis as more evidence or information becomes available. This concept is the backbone of the **Naive Bayes** machine learning algorithm.

---

## 1. Types of Events

Before diving into the theorem, it is essential to distinguish between how events interact with one another.

### Independent Events

An event is **independent** if its outcome does not affect the probability of another event.

* **Examples:** Rolling a dice or tossing a coin.
* **Logic:** If you flip a head, the probability of getting a head on the next flip remains 0.5. The first flip does not change the odds of the second.

### Dependent Events

An event is **dependent** if its outcome changes the probability of subsequent events.

* **Example:** Drawing marbles from a bag without replacement.
* If a bag has 3 yellow and 2 red marbles (Total = 5), the probability of picking red is 2/5.
* If you keep that red marble, the bag now has 4 marbles. The probability of then picking a yellow marble becomes 3/4.


* **Logic:** The first event "impacted" the second by changing the sample space.

## 2. Conditional Probability

**Conditional Probability** is the likelihood of an event occurring, given that another event has already occurred. This is written as **P(A|B)**, read as "Probability of A given B."

## 3. Bayes' Theorem

By rearranging the formula for dependent events (Commutative Property: P(A and B) = P(B and A)), we derive **Bayes' Theorem**:

**P(A|B) = [P(A) * P(B|A)] / P(B)**

### Definition of Terms:

* **P(A|B):** **Posterior Probability** (The probability of hypothesis A given the evidence B).
* **P(B|A):** **Likelihood** (The probability of evidence B given that hypothesis A is true).
* **P(A):** **Prior Probability** (The initial probability of A before seeing the evidence).
* **P(B):** **Marginal Likelihood** (The total probability of the evidence B).

---

## 4. Application in Machine Learning (Naive Bayes)

In Machine Learning, we use Bayes' Theorem to predict an output (**y**) based on several input features (**x1, x2, x3**).

### Real-World Example: House Pricing

Imagine you want to predict if a house price is "High" or "Low" based on:

* **x1:** Size of the house
* **x2:** Number of rooms
* **x3:** Location

The formula transforms into:
**P(y | x1, x2, x3) = [P(y) * P(x1, x2, x3 | y)] / P(x1, x2, x3)**

### Why "Naive"?

The algorithm is called **Naive Bayes** because it makes a "naive" assumption that all features (size, rooms, location) are **independent** of each other, even though in real life they often correlate. This simplification makes the math much faster and works surprisingly well for complex tasks like spam filtering and document classification.
