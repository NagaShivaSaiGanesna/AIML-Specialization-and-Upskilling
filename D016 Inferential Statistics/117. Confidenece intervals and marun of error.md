# Confidence Interval and Margin of Error

In statistics, we often use a **Point Estimate** (like the sample mean, **x-bar**) to guess a population parameter (like the population mean, **mu**). However, a single number is rarely 100% accurate. To account for uncertainty, we use a **Confidence Interval (CI)**, which provides a range of values where we believe the true population parameter lies.

---

## 1. Core Concepts

### Point Estimate

A **Point Estimate** is a single value used to estimate a population parameter. For example, using **x-bar** to estimate **mu**. The downside is that different samples will produce different point estimates, leading to potential errors.

### Confidence Interval (CI)

A **Confidence Interval** is a range of values, derived from sample statistics, that is likely to contain the value of an unknown population parameter. It is defined by a **Confidence Level** (e.g., 95%).

### Margin of Error

The **Margin of Error** represents the maximum expected difference between the true population parameter and the sample estimate. It tells you how many percentage points your results will differ from the real population value.

---

## 2. Mathematical Formulas

The general formula for calculating a Confidence Interval is:

**Confidence Interval = Point Estimate + or - Margin of Error**

### For Z-Test (Population Standard Deviation is Known)

Use this when you know **sigma** and the sample size is large.

**CI = x-bar + or - [z * (sigma / root n)]**

* **x-bar**: Sample Mean
* **z**: Z-score (critical value based on confidence level, e.g., 1.96 for 95%)
* **sigma**: Population Standard Deviation
* **n**: Sample Size

### For T-Test (Population Standard Deviation is Unknown)

Use this when you only have the sample standard deviation (**s**).

**CI = x-bar + or - [t * (s / root n)]**

* **t**: T-score (requires **Degrees of Freedom**, which is **n - 1**)
* **s**: Sample Standard Deviation

---

## 3. Step-by-Step Calculation (Z-Test Example)

**Problem:** On the verbal section of the CAT exam, the population standard deviation (**sigma**) is 100. A sample of 30 test-takers has a mean (**x-bar**) of 520. Construct a **95% Confidence Interval**.

### Step 1: Identify Knowns

* **x-bar** = 520
* **sigma** = 100
* **n** = 30
* **Confidence Level** = 95% (Alpha = 0.05)

### Step 2: Find the Critical Value (z)

For a 95% confidence level in a two-tailed test, the area in each tail is **0.025**. Looking at the Z-table for an area of **0.9750** (1 - 0.025):

* **z** = 1.96

### Step 3: Calculate Margin of Error

**Margin of Error = 1.96 * (100 / root 30)**
*(Note: If n was 25 as mentioned in the verbal slip of the transcript, the calculation would be 1.96 * (100 / 5) = 39.2)*

### Step 4: Calculate the Range

* **Lower Bound** = 520 - 39.2 = **480.8**
* **Upper Bound** = 520 + 39.2 = **559.2**

**Conclusion:** We are **95% confident** that the true average CAT score for the population is between **480.8** and **559.2**.

---

## 4. Summary Table: Z vs. T for Confidence Intervals

| Feature | Z-Interval | T-Interval |
| --- | --- | --- |
| **Prerequisite** | **sigma** is known | **sigma** is unknown |
| **Sample Size** | Ideally **n > 30** | Usually **n < 30** |
| **Critical Value** | Fixed for Confidence Level | Varies with **Degrees of Freedom** |
| **Distribution** | Normal Distribution | T-Distribution |

---

## Key Terminology

* **Alpha (a):** The significance level (e.g., 0.05 for 95% confidence).
* **Critical Value:** The number of standard deviations you move away from the mean to capture the desired area of the distribution.
* **Standard Error:** The term **sigma / root n**, which measures the standard deviation of the sampling distribution.
