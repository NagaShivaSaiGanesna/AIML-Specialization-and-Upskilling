# Z-Test: Statistical Analysis for Means

A **Z-test** is a statistical test used to determine whether there is a significant difference between sample and population means or between two sample means. It is primarily used when dealing with averages and follows specific criteria to ensure accuracy.

---

## When to Use a Z-Test

To apply a Z-test, two critical conditions must be met:

1. **Known Population Standard Deviation (sigma)**: You must know the standard deviation of the entire population.
2. **Sample Size (n)**: The sample size must be **greater than or equal to 30**.

### Comparison of Statistical Tests

| Test Type | Primary Use Case |
| --- | --- |
| **Z-Test** | Comparing means when **sigma** is known and **n >= 30**. |
| **T-Test** | Comparing means when **sigma** is unknown or **n < 30**. |
| **Chi-Square** | Analyzing **categorical data**. |
| **ANOVA** | Analyzing the **variance** between three or more groups. |

## Step-by-Step Problem 1: City Resident Heights (Two-Tailed)

**Problem**: Average city height is **168 cm** (mu) with a standard deviation of **3.9** (sigma). A doctor samples **36 individuals** (n) and finds an average height of **169.5 cm** (x-bar). Test at a **95% confidence interval**.

### 1. State Hypotheses

* **Null Hypothesis (H0)**: mu = 168 cm (The average height is 168 cm).
* **Alternate Hypothesis (H1)**: mu != 168 cm (The average height is different).

### 2. Set Decision Boundary

* **Confidence Interval (CI)**: 0.95.
* **Significance Value (alpha)**: 1 - 0.95 = **0.05**.
* **Critical Z-score**: For a two-tailed test at 0.05 alpha, the area in each tail is 0.025. Using a Z-table, the area of 0.9750 (1 - 0.025) corresponds to a Z-score of **+/- 1.96**.

### 3. Perform Statistical Analysis

Calculate the **Calculated Z-score (Z-test)** using the formula:
**Z = (x-bar - mu) / (sigma / root(n))**.

* Z = (169.5 - 168) / (3.9 / root(36))
* Z = 1.5 / 0.65 = **2.31**

### 4. Conclusion

* **Compare Z-scores**: 2.31 is greater than 1.96.
* **Compare P-values**: The p-value for Z=2.31 is **0.02088**, which is less than alpha (0.05).
* **Result**: **Reject the Null Hypothesis**. The average height is significantly different (specifically, it appears to be increasing).

## Step-by-Step Problem 2: Bulb Warranty (One-Tailed)

**Problem**: Bulbs have a **5-year** average warranty (mu) and a **0.50** standard deviation (sigma). A worker believes bulbs malfunction in **less than** 5 years. A sample of **40 bulbs** (n) shows an average of **4.8 years** (x-bar). Test at **98% confidence**.

### 1. State Hypotheses

* **H0**: mu = 5 years.
* **H1**: mu < 5 years (One-tailed test).

### 2. Set Decision Boundary

* **alpha**: 1 - 0.98 = **0.02**.

### 3. Perform Statistical Analysis

* **Z = (4.8 - 5) / (0.50 / root(40))**
* **Z = -2.53**
* **P-value**: From the Z-table, the area for Z = -2.53 is **0.0057**.

### 4. Conclusion

* **Compare**: Is the p-value (0.0057) less than alpha (0.02)?
* **Result**: **Yes (Reject H0)**. There is enough evidence to support the worker's belief that bulbs malfunction in less than 5 years.
