# Probability Mass Function (PMF)

A **PMF** is the fundamental way we describe the probability of **discrete** events. Think of it as a "probability map" for data that you can count.

## Definition

The **Probability Mass Function (PMF)** is a mathematical function that provides the **exact probability** for every possible outcome of a **discrete random variable**.

In two lines:

* It maps each specific outcome to its exact likelihood of occurring.
* It ensures all individual probabilities are non-negative and sum up to exactly **1**.

---

## Key Characteristics

* **Applicability:** Only used for **Discrete** variables (things you count, like 1, 2, 3).
* **Direct Output:** Unlike continuous functions, the PMF gives you the answer directly. If  is 5,  is the literal probability of 5 happening.
* **Visualization:** Usually represented as a **Bar Chart** or **Stem Plot** because there is "nothing" between the values.

## Real-World Example: API Status Monitoring

As a Data Engineer, imagine you are tracking the health of a data ingestion service. The outcomes are discrete status codes.

### The PMF Table

| Status Code (x) | Probability P(X=x) | Context |
| --- | --- | --- |
| **200** | **0.92** | Success (Healthy) |
| **401** | **0.03** | Unauthorized (Auth Token Expired) |
| **404** | **0.04** | Not Found (Broken URL) |
| **500** | **0.01** | Internal Error (Server Crash) |

### Why this follows PMF Rules:

1. **No Negative Values:** You can't have a -5% chance of a server crash.
2. **Sum of 1:** . This means we have accounted for **100%** of the possible outcomes in our system.

## Comparison: PMF vs. Common Sense

| Feature | Using "Common Sense" | Using a **PMF** |
| --- | --- | --- |
| **Complexity** | Good for a simple coin toss. | Essential for complex systems (like predicting server load). |
| **Math** | Mental estimation. | Uses formulas (like **Binomial** or **Poisson**) to find answers. |
| **Scale** | Hard to do for 1,000+ events. | Scales perfectly using code or spreadsheets. |
