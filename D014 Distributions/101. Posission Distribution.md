# Poisson Distribution

The **Poisson Distribution** is a **discrete probability distribution** that models the number of events occurring within a **fixed interval of time or space**. It is a vital tool for predicting the frequency of random events when you know the average rate of occurrence.

## 1. Core Concepts

* **Discrete Data**: It applies to **discrete random variables**, meaning outcomes are countable whole numbers like 0, 1, 2....
* **Fixed Intervals**: It describes events occurring in **fixed time intervals** (e.g., every hour) or spatial intervals.
* **Independent Events**: Each event occurs **independently** of the time since the last event.
* **Constant Rate**: Events happen at a **known constant mean rate**.

---

## 2. Real-World Examples

* **Hospital/Bank Visits**: Tracking the number of people visiting a branch every hour.
* **Network Failures**: Monitoring the number of API or server failures in a fixed window.
* **Customer Traffic**: Predicting how many users will hit a website at 2 p.m. vs 5 p.m..

---

## 3. The Parameter: lambda

The distribution is defined by a single parameter called **lambda**.

* **Definition**: Lambda represents the **expected number of events** (the average) occurring in every time interval.
* **Behavior**: As the lambda value increases, the distribution shifts to the right and begins to resemble a symmetrical **bell curve**.

---

## 4. Probability Mass Function (PMF)

Because Poisson deals with discrete data, it uses a **PMF** to calculate the probability of exactly **x** events occurring.

**Standard Text Notation:** **P(x; lambda) = (e^-lambda * lambda^x) / x-factorial**

* **e**: Euler's number (approximately 2.718).
* **lambda**: The expected average rate.
* **x**: The specific number of occurrences you want to find the probability for.
* **x-factorial**: The product of all positive integers up to x.

---

## 5. Statistical Properties

A unique feature of the Poisson distribution is that its mean and variance are identical.

* **Mean (mu)**: lambda
* **Variance (sigma squared)**: lambda
* **Standard Deviation (sigma)**: square root of lambda

---

## Binomial vs. Poisson Distribution

| Feature | Binomial Distribution | Poisson Distribution |
| --- | --- | --- |
| **Basis** | Number of successes in a fixed number of trials (n). | Number of events in a fixed interval of time/space. |
| **Requirements** | Needs the total number of trials and success probability. | Only needs the constant mean rate (lambda). |
| **Outcomes** | Binary (Success or Failure). | Count of occurrences (0 to infinity). |

# Poisson Practice: Server Errors

### The Scenario

Your data pipeline logs show that, on average, your server experiences **2 minor errors per day**. You want to know the probability that exactly **3 errors** will occur tomorrow.

### 1. Identify the Parameters

* **Average Rate (lambda):** 2
* **Target Events (x):** 3
* **Euler's Number (e):** Approximately 2.718

### 2. Apply the PMF Formula

We use the **Poisson PMF** to calculate this specific probability:

### 3. Step-by-Step Calculation

1. **Calculate e^-lambda:** 2.718 to the power of -2 = **0.135**
2. **Calculate lambda^x:** 2 to the power of 3 = **8**
3. **Calculate x-factorial (3!):** 3 * 2 * 1 = **6**
4. **Final Result:** (0.135 * 8) / 6 = **0.180**

**Result:** There is an **18% probability** that you will see exactly 3 errors tomorrow.
