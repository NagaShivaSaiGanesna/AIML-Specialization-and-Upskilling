# Bernoulli Distribution

The **Bernoulli Distribution** is the most basic building block in statistics. It is the "atom" of all discrete distributions.

## 1. The Core Concept

A **Bernoulli Distribution** represents a **single trial** (one event) that has exactly **two possible outcomes**:

* **Success (1):** Occurs with probability **p**.
* **Failure (0):** Occurs with probability **q** (where **q = 1 - p**).

### The "Feel" in 2 Lines

**Bernoulli is the "Story" of a single Yes/No event, like flipping a coin once or a single server request succeeding.**

**It uses the PMF "Language" to map these two outcomes to their exact probabilities so the total equals 1.**

---

## 2. The Relationship: Distribution vs. PMF

It is common to get confused between the name of the pattern and the tool used to describe it.

* **PMF (Probability Mass Function):** This is the **Format** or the "Language." It is the general method we use for all discrete data.
* **Bernoulli:** This is the **Specific Pattern** or the "Story." It is a specific type of PMF.

---

## 3. Probability Mass Function (PMF)

The PMF of a Bernoulli distribution is the "lookup table" that defines the probability for the two possible outcomes ().

| Outcome (x) | Probability P(x) |
| --- | --- |
| **1 (Success)** | **p** |
| **0 (Failure)** | **1 - p** |

**The Formula:** For a single trial, the math is expressed as:
**f(x) = p^x * (1 - p)^(1 - x)**

---

## 4. Statistical Properties

Because the distribution is so simple, its properties are very direct:

* **Mean (mu):** p
* **Variance (sigma squared):** p * q (or p * (1 - p))
* **Standard Deviation (sigma):** square root of (p * q)

---

## 5. Real-World Example: Data Validation

As a Data Engineer at **Accordion**, imagine you are running a validation check on **one single record** to see if it contains a Null value.

* **p = 0.02** (2% chance the record is Null/Failure)
* **q = 0.98** (98% chance the record is Valid/Success)

Looking at this single row is a **Bernoulli Trial**. If you were to look at a batch of 1,000 rows to count the total number of Nulls, you would then be moving into a **Binomial Distribution**.
