# Uniform Distribution: Continuous and Discrete

In statistics, a **Uniform Distribution** describes a scenario where every possible outcome within a specific range is equally likely to occur. Because the probability is "uniform" across the range, the visualization of this distribution typically looks like a rectangle, leading many to call it the **Rectangular Distribution**.

---

## Continuous Uniform Distribution

The **Continuous Uniform Distribution** is used for **Continuous Random Variables**—variables that can take any value within a range (like height, time, or temperature).

### Core Characteristics

* **Bounds:** The distribution is defined by two parameters: **a** (the minimum value) and **b** (the maximum value).
* **Probability Density Function (PDF):** Since every value between **a** and **b** is equally likely, the "height" of the distribution is constant.
* **Total Area:** The area under the PDF curve must always equal 1.

### Mathematical Formulas

| Metric | Formula |
| --- | --- |
| **PDF** (Probability Density Function) | 1 / (b - a) |
| **Mean** (Expected Value) | (a + b) / 2 |
| **Median** | (a + b) / 2 |
| **Variance** | ((b - a) * (b - a)) / 12 |

### Cumulative Distribution Function (CDF)

The **CDF** calculates the probability that a random variable **X** will be less than or equal to a specific value **x**.

* If **x** is less than **a**: The probability is 0.
* If **x** is between **a** and **b**: The formula is **(x - a) / (b - a)**.
* If **x** is greater than **b**: The probability is 1 (100%).

---

## Practical Example: Candy Shop Sales

Imagine a shop where the number of candies sold daily is uniformly distributed between a **minimum (a) of 10** and a **maximum (b) of 40**.

**1. Calculate the PDF height:**
PDF = 1 / (b - a)
PDF = 1 / (40 - 10) = **1 / 30**

**2. Find the probability of selling between 15 and 30 candies:**
To find the probability between two points (**x1** and **x2**), we find the area of the rectangle between those points:
Probability = (x2 - x1) * (1 / (b - a))
Probability = (30 - 15) * (1 / 30)
Probability = 15 * (1 / 30) = **0.5 (or 50%)**

**3. Find the probability of selling more than 20 candies:**
Here, our range is from 20 (**x1**) to the maximum of 40 (**b**).
Probability = (40 - 20) * (1 / 30)
Probability = 20 / 30 = **0.66 (or 66.6%)**

## Discrete Uniform Distribution

The **Discrete Uniform Distribution** applies when the random variable is **discrete** (countable values, like integers) and each outcome has an equal probability.

### Core Characteristics

* **Finite Outcomes:** There are a specific number of outcomes (**n**).
* **Probability Mass Function (PMF):** Each outcome has a probability of **1 / n**.
* **Example:** Rolling a fair 6-sided die. Each number (1 through 6) has a 1/6 probability.

### Mathematical Formulas

| Metric | Formula |
| --- | --- |
| **Number of Outcomes (n)** | b - a + 1 |
| **PMF** (Probability Mass Function) | 1 / n |
| **Mean** | (a + b) / 2 |

### Key Differences: Continuous vs. Discrete

| Feature | Continuous Uniform | Discrete Uniform |
| --- | --- | --- |
| **Variable Type** | Continuous (Infinite decimals) | Discrete (Countable steps) |
| **Function Type** | Probability Density Function (PDF) | Probability Mass Function (PMF) |
| **Visualization** | Solid Rectangle | Individual Bars of equal height |
| **Examples** | Waiting time, measurement errors | Die rolls, coin flips, lottery draws |

---

## Summary of Parameters

* **a**: The lower boundary (minimum).
* **b**: The upper boundary (maximum).
* **n**: The total number of possible discrete outcomes.
* In both distributions, the **Mean** and **Median** are identical, located exactly in the center of the range.
