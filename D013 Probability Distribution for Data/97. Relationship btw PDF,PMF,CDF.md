# Probability Functions in Data Science

## 1. Probability Mass Function (PMF)

The **PMF** is used exclusively for **Discrete Random Variables**. These are variables where you can clearly count the outcomes (like 1, 2, 3).

* **Definition:** It tells you the exact probability that a variable will equal a specific value.
* **The "Point" Rule:** In a discrete setup, you can ask, "What is the chance of exactly X?" and get a direct answer.
* **Visualization:** It looks like a **Bar Chart** or "sticks" because there is no data between the points (e.g., you can't roll a 2.5 on a standard die).

### Example: Rolling a Die

If you roll a fair six-sided die, the possible outcomes are {1, 2, 3, 4, 5, 6}.

* **P(X=4):** The probability of rolling exactly a 4 is **1/6**.
* All individual probabilities in a PMF must add up to **1**.

---

## 2. Probability Density Function (PDF)

The **PDF** is used for **Continuous Random Variables**. These are variables that can take any value within a range, like height, weight, or the exact time it takes for a website to load.

* **The "Exact Point" Paradox:** For continuous data, the probability of an exact point is technically **0**. For example, the chance of someone being exactly 175.000000... cm tall (to infinite decimals) is impossible to hit.
* **Area Under the Curve:** Instead of looking at points, we look at **ranges**. We calculate the probability by finding the area under the curve between two points.
* **Total Area:** The total area under the entire curve always equals **1** (100% probability).
* **Gradient Relationship:** The density at a specific point represents the **slope (gradient)** of the Cumulative Distribution Function (CDF) at that same point.

---

## 3. Cumulative Distribution Function (CDF)

The **CDF** is the "Running Total" of probability. It tells you the chance that a variable will be **less than or equal to** a certain value.

* **Discrete Calculation:** For a die, the probability of rolling a 3 or less is:
* P(X <= 3) = P(1) + P(2) + P(3) = 1/6 + 1/6 + 1/6 = **3/6 (or 50%)**.


* **Continuous Calculation:** If you are looking at house prices and the CDF at $500,000 is 0.85, it means there is an **85% chance** a house costs $500,000 or less.
* **Visual Trend:** A CDF graph always moves upward (or stays flat) but never goes down, eventually reaching a height of 1.

---

## Summary of Distribution Types

| Distribution Type | Function Type | Use Case Example |
| --- | --- | --- |
| **Bernoulli** | PMF | Single "Yes/No" events (e.g., flipping a coin once). |
| **Binomial** | PMF | Multiple "Yes/No" events (e.g., how many heads in 10 flips). |
| **Normal (Gaussian)** | PDF | The "Bell Curve" (e.g., human heights, IQ scores). |
| **Poisson** | PMF | Number of events in a fixed time (e.g., customers arriving per hour). |
| **Log-Normal** | PDF | Skewed data where values can't be negative (e.g., house prices). |
| **Uniform** | PMF/PDF | Every outcome is equally likely (e.g., a fair spinner). |

---

## Application in Data Science

In a project like **House Price Prediction**, understanding these functions helps you handle data correctly:

* **Continuous Features (PDF):** Price, Square Footage, and Acreage. You use PDFs to see if the data is "Normal" or if it needs to be transformed to remove skewness.
* **Discrete Features (PMF):** Number of Bedrooms, Floor Number, or Zip Code. You use PMFs to understand the frequency of these categories.
