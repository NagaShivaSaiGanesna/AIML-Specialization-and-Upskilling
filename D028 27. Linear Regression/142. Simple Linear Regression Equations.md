## The Mathematics of the Best Fit Line

In Simple Linear Regression, we represent the relationship between our input $x$ and output $y$ using the equation of a straight line.

### 1. The Linear Equation

The standard mathematical representation for the prediction is:

$$ŷ = mx + c$$

Or, in more technical machine learning notation:

$$ŷ = β₀ + β₁x$$

| Component | Professional Term | Meaning |
| --- | --- | --- |
| **ŷ (y-hat)** | **Predicted Value** | The output the model gives you for a given $x$. |
| **x** | **Input Feature** | The data you provide (e.g., Weight). |
| **m (or β₁)** | **Slope / Coefficient** | How much $y$ changes for every 1-unit increase in $x$. |
| **c (or β₀)** | **Intercept / Bias** | The value of $y$ when $x$ is zero. |

---

### 2. Finding the "Optimal" $m$ and $c$

To find the best fit line, we use a method called **Ordinary Least Squares (OLS)**. The goal is to minimize the **Sum of Squared Errors (SSE)**.

We square the errors because:

1. It makes all values positive (so errors above and below the line don't cancel each other out).
2. It penalizes larger errors more heavily.

#### The Formulas:

To calculate the slope (**m**) and intercept (**c**) directly from your data, we use the following:

**The Slope ($m$):**


$$m = Σ((x - x̄)(y - ȳ)) / Σ(x - x̄)²$$

**The Intercept ($c$):**


$$c = ȳ - mx̄$$

*(Note: $x̄$ and $ȳ$ represent the **mean** (average) of all $x$ and $y$ values in your dataset.)*

---

### 3. Cost Function: Mean Squared Error (MSE)

In machine learning, we evaluate how "bad" our line is using a **Cost Function**. For linear regression, we typically use **Mean Squared Error (MSE)**.

$$MSE = (1/n) * Σ(y - ŷ)²$$

As an educator, I like to visualize this as a "valley." The algorithm's job is to find the bottom of this valley where the error is the lowest. This process of moving down the valley is what we call **Optimization**.

---

### Summary of the Learning Process

1. **Initialize:** Start with a random line (random $m$ and $c$).
2. **Predict:** Calculate $ŷ$ for all $x$ values.
3. **Calculate Error:** Use the MSE formula to see how far off the line is.
4. **Adjust:** Change $m$ and $c$ to reduce the MSE (using OLS or Gradient Descent).
5. **Repeat:** Continue until the error is minimized and the **Best Fit Line** is found.
