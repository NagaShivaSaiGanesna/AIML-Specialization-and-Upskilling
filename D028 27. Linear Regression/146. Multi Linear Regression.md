# Multiple Linear Regression

While **Simple Linear Regression** helps us understand the relationship between two variables, real-world problems are rarely that simple. **Multiple Linear Regression** is an extension of that logic, used when we want to predict a dependent variable based on the values of **two or more** independent variables.

---

## 1. Defining the Core Difference

The transition from simple to multiple linear regression is primarily defined by the number of input features (independent variables).

| Feature | Simple Linear Regression | Multiple Linear Regression |
| --- | --- | --- |
| **Independent Variables ($x$)** | Exactly one (e.g., Weight) | Two or more (e.g., Rooms, Size, Location) |
| **Dependent Variable ($y$)** | Exactly one (e.g., Height) | Exactly one (e.g., House Price) |
| **Geometric Shape** | A 2D Best Fit Line | A 3D Plane or $n$-Dimensional Hyperplane |

---

## 2. The Mathematical Equation

In Multiple Linear Regression, each input feature gets its own **coefficient** (slope), but there is still only **one intercept** for the entire model.

### The Equation:

**hθ(x) = θ₀ + θ₁x₁ + θ₂x₂ + θ₃x₃ + ... + θₙxₙ**

* **θ₀ (Theta Zero):** The **Intercept**. It represents the baseline value when all input features are zero.
* **x₁, x₂, x₃...:** The **Input Features** (e.g., $x_{1}$ = Number of rooms, $x_{2}$ = Size in sq ft).
* **θ₁, θ₂, θ₃...:** The **Coefficients** for each feature. These tell us how much the output changes for every unit increase in that specific feature, assuming others stay constant.

---

## 3. High-Dimensional Gradient Descent

In Multiple Linear Regression, we are no longer looking for the bottom of a 2D "valley." We are looking for the **Global Minima** of an $n$-dimensional cost surface.

### The Optimization Goal:

We must simultaneously update every coefficient until the cost function **J(θ₀, θ₁, ..., θₙ)** is minimized.

* Each parameter starts at a random point.
* The convergence algorithm calculates the gradient (direction of steepest descent) for every $\theta$ value.
* The model "walks" down the multi-dimensional surface to reach the point where the error is minimal.

---

## 4. Why Use Multiple Linear Regression?

In a scenario like **House Pricing**, predicting the price based solely on "Number of Rooms" is inaccurate. By including "Square Footage," "Neighborhood Score," and "Year Built," we provide the model with a richer context, leading to a much more accurate prediction.

> **Technical Insight:** As we add more features, we must be careful of **Overfitting**—where the model learns the noise in the data rather than the actual pattern. We will cover how to handle this in future modules on Regularization.
