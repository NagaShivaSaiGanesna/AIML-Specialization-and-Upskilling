# Simple Linear Regression

**Simple Linear Regression** is a foundational supervised learning algorithm used to solve **Regression** problems. It is the building block for more complex architectures, including Artificial Neural Networks (ANN).

---

## 1. Core Concept

The goal of Simple Linear Regression is to model the relationship between **one independent feature** (input) and **one dependent feature** (output).

* **Independent Variable (x):** The input you provide to the model (e.g., Weight).
* **Dependent Variable (y):** The value you want to predict (e.g., Height).

When we have only one input feature, we call it **Simple** Linear Regression. If we were to use multiple inputs (e.g., Weight, Age, and Gender), it would become **Multiple Linear Regression**.

---

## 2. Geometric Interpretation: The Best Fit Line

In a 2D space, the model represents the data as a series of points on a graph. The objective of the algorithm is to find the **Best Fit Line** through these points.

### How Predictions are Made

Once the model is trained and the line is drawn, predicting a new value is straightforward:

1. Locate the new input value (Weight) on the horizontal axis (x).
2. Move vertically until you hit the Best Fit Line.
3. The corresponding value on the vertical axis (y) is your predicted Height.

---

## 3. Defining the "Best" Fit (Error Minimization)

How does the algorithm decide which line is the "best"? It uses the concept of **Error** (also known as residuals).

* **True Points:** The actual data values from your training set.
* **Predicted Points:** The points located exactly on the Best Fit Line for a given x.
* **Residual (Error):** The vertical distance between a True Point and the Predicted Point.

$$Error = y_{true} - y_{predicted}$$

### The Goal

The algorithm tries to position the line such that the **summation of all these errors is minimized**. By reducing the total distance between the line and the actual data points, the model ensures the highest possible accuracy for future predictions.

---

## 4. Why it Matters

Understanding this algorithm is crucial because:

* **Intuition:** it teaches you how models handle continuous numerical data.
* **Math Foundation:** The concept of minimizing error (Optimization) is the same principle used to train deep learning models.
* **Scalability:** The logic of the "line" in 2D scales to "hyperplanes" in high-dimensional space.
