# Error Metrics: MSE, MAE, and RMSE

In linear regression, while **R-Squared** and **Adjusted R-Squared** tell us the percentage of variance explained, error metrics like **Mean Squared Error (MSE)**, **Mean Absolute Error (MAE)**, and **Root Mean Squared Error (RMSE)** focus on the specific distance between your predictions and the actual truth.

---

## 1. Mean Squared Error (MSE)

**MSE** is the average of the squared differences between the actual values and the predicted values.

### The Formula

**MSE = (1 / n) * Σ (yᵢ - ŷᵢ)²**

### Advantages

* **Differentiability:** Because the error is squared, the equation is quadratic. When plotted, it forms a smooth, convex **Gradient Descent** curve. This makes it mathematically easier to find the global minimum.
* **Optimization:** It has exactly one global minimum, ensuring that the optimization process doesn't get "stuck" in a local valley.
* **Faster Convergence:** The model can find the best fit line relatively quickly.

### Disadvantages

* **Sensitivity to Outliers:** Since errors are squared, large errors (outliers) are penalized much more heavily than small ones. This can "pull" the best fit line toward the outlier, ruining the model's accuracy for the rest of the data.
* **Unit Mismatch:** If you are predicting salary in "Lakhs," the MSE will be in "Lakhs squared," which is difficult to interpret intuitively.

---

## 2. Mean Absolute Error (MAE)

**MAE** is the average of the absolute differences between the actual and predicted values.

### The Formula

**MAE = (1 / n) * Σ |yᵢ - ŷᵢ|**

### Advantages

* **Robust to Outliers:** Unlike MSE, it does not square the error. An outlier will only increase the error linearly, making the best fit line more stable.
* **Unit Consistency:** The error is in the same units as the output (e.g., if you're predicting "Lakhs," the error is in "Lakhs").

### Disadvantages

* **Optimization Complexity:** The absolute value function creates a V-shaped curve rather than a smooth U-shape. At the very bottom (zero), it is **not differentiable**, which requires complex techniques like sub-gradients.
* **Slower Convergence:** It generally takes much longer to find the optimal point compared to MSE.

## 3. Root Mean Squared Error (RMSE)

**RMSE** is simply the square root of the MSE. It serves as a middle ground between MSE and MAE.

### The Formula

**RMSE = √ [ (1 / n) * Σ (yᵢ - ŷᵢ)² ]**

### Advantages

* **Unit Consistency:** Like MAE, it brings the error back to the original units (e.g., "Lakhs").
* **Differentiability:** Since it is based on the MSE formula, it maintains the smooth gradient descent property.

### Disadvantages

* **Outlier Sensitivity:** Because the squaring happens *before* the square root, it is still highly sensitive to outliers.

---

## 4. Summary Matrix: Which Metric to Choose?

| Metric | Differentiable? | Robust to Outliers? | Units Match Output? | Primary Use Case |
| --- | --- | --- | --- | --- |
| **MSE** | Yes | No | No | Optimization & Math training. |
| **MAE** | No (at zero) | **Yes** | **Yes** | Dealing with noisy data. |
| **RMSE** | Yes | No | **Yes** | Interpreting results clearly. |

---

### Comparison of Minima Behavior

When training a model, it is vital to know if your cost function is **Convex** (like MSE) or **Non-Convex**. A non-convex function can have multiple local minima, causing your model to "think" it has found the best solution when it actually hasn't.
