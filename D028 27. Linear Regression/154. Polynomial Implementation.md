# Implementation Project: Polynomial Regression on Non-Linear Data

This guide walks through the practical implementation of **Polynomial Regression** to model a non-linear dataset. We will generate synthetic data using a quadratic equation and demonstrate how polynomial transformation significantly improves model accuracy over standard linear regression.

---

## 1. Generating a Non-Linear Dataset

To simulate real-world non-linear relationships, we create a dataset based on a **Quadratic Equation** with added noise (outliers).

### The Mathematical Formula

We use the following form to generate our target variable ($y$):


$$y = 0.5x^2 + 1.5x + 2 + \epsilon$$


Where:

* **0.5x²**: The quadratic term that creates the curve.
* **1.5x**: The linear component.
* **2**: The intercept (bias).
* **ε (epsilon)**: Random noise/outliers generated using `numpy.random`.

### Visualization

Plotting this data reveals a clear curve. A straight line (Simple Linear Regression) would result in a high **Residual Sum of Squares (RSS)** because it cannot "bend" to follow the points.

---

## 2. The Baseline: Simple Linear Regression

We first attempt to fit the data using standard `LinearRegression`.

* **Model Accuracy ($R^2$):** Approximately **0.62**.
* **Observation:** The best-fit line passes through the middle of the curve but misses the trajectory of the points at both ends.

---

## 3. Polynomial Transformation

To fix the underfitting, we apply a **Polynomial Transformation**. This process adds new features to our dataset that are powers of the original feature.

### Using `PolynomialFeatures`

We use Scikit-Learn's `PolynomialFeatures(degree=2, include_bias=True)`.

* **Input:** A single feature $[x_1]$.
* **Output:** Three features $[1, x_1, x_1^2]$.

| Original Feature | Polynomial Feature (Degree 2) |
| --- | --- |
| $x_1$ | $1$ (Bias/Intercept) |
|  | $x_1$ (Linear term) |
|  | $x_1^2$ (Quadratic term) |

> **Critical Step:** We use `fit_transform` on the training data and only `transform` on the test data to prevent **Data Leakage**.

---

## 4. Model Training and Results

After the transformation, we train a `LinearRegression` model on the expanded features $[1, x, x^2]$.

* **Model Accuracy ($R^2$):** Increases to **0.93 - 0.94**.
* **Coefficients:** The model successfully retrieves the original coefficients (approx. $0.5$ for $x^2$ and $1.5$ for $x$).

### The New Best-Fit Line

When visualized, the prediction line is no longer straight; it is a smooth curve that follows the data points closely.

---

## 5. Predicting New Data

When we receive new, unseen data, we must follow these steps:

1. **Transform:** Use the existing `poly` object to transform the new data into the same degree (e.g., $x$ becomes $[1, x, x^2]$).
2. **Predict:** Pass the transformed features into the trained regression model.

---

## 6. Summary of Performance

| Algorithm | $R^2$ Score | Fit Status |
| --- | --- | --- |
| **Simple Linear Regression** | ~0.62 | Underfitting |
| **Polynomial Regression (Degree 2)** | ~0.94 | **Generalized Fit** |
| **Polynomial Regression (Degree 10+)** | ~0.99 (Train) / Lower (Test) | Overfitting |

As seen in the experiments, **Degree 2** provided the best balance. Increasing the degree to 3 or higher did not significantly improve the score for this specific quadratic dataset and could eventually lead to overfitting.
