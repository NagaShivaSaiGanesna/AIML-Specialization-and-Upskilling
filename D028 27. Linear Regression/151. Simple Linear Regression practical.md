# Practical Implementation: Simple Linear Regression (Weight vs. Height)

This guide walks through a hands-on project to predict **Height** (dependent variable) based on **Weight** (independent variable) using Python. We will compare the industry-standard **Scikit-Learn** implementation with the mathematical **OLS (Ordinary Least Squares)** approach.

---

## 2. Data Preprocessing

### Feature Engineering: The 2D Array Rule

**Crucial Step:** Scikit-Learn's `fit()` method expects the independent variable ($X$) to be a **2D array** or a **DataFrame**, even if it's just one column. The dependent variable ($y$) can remain a 1D series.

```python
# Independent feature (must be 2D)
X = df[['weight']] 

# Dependent feature (1D is fine)
y = df['height']

```

### Train-Test Split

We split the data to prevent **overfitting**. We train on one portion and validate the "unseen" performance on the test portion.

* **Test Size:** 25%
* **Random State:** 42 (ensures reproducibility)

### Standardization (Z-Score Scaling)

Since Linear Regression uses Gradient Descent internally, features with different units can slow down convergence. We scale the data so the mean is $0$ and the standard deviation is $1$.

$$z = \frac{x_i - \mu}{\sigma}$$

> **Data Leakage Warning:** Always use `fit_transform()` on the **Training set** but only `transform()` on the **Test set**. This ensures the model doesn't "peek" at the distribution of the test data.

---

## 3. Model Training (Scikit-Learn)

```python
from sklearn.linear_model import LinearRegression

regression = LinearRegression()
regression.fit(X_train, y_train)

print(f"Coefficient (Slope): {regression.coef_}")
print(f"Intercept: {regression.intercept_}")

```

* **Coefficient ($\beta_1$):** Approx **17.29**. This means for every 1-unit increase in scaled weight, height increases by 17.29 units.
* **Intercept ($\beta_0$):** Approx **156.47**. This is the predicted height when the scaled weight is zero.

---

## 4. Evaluation and Performance Metrics

After predicting the test set ($y_{pred}$), we evaluate how "off" our predictions are.

| Metric | Formula / Description | Result in Project |
| --- | --- | --- |
| **MSE** | Mean Squared Error; penalizes large errors. | ~114.84 |
| **MAE** | Mean Absolute Error; average of absolute errors. | ~9.66 |
| **RMSE** | Root of MSE; brings units back to the original scale. | ~10.71 |
| **$R^2$ Score** | Proportion of variance explained by the model. | **0.73 (73%)** |

---

## 5. Comparison: OLS via Statsmodels

We can achieve the same results using the `statsmodels` library, which provides a much more detailed statistical summary.

```python
import statsmodels.api as sm

model = sm.OLS(y_train, X_train).fit()
print(model.summary())

```

**Observation:** The coefficient obtained via OLS (**17.29**) perfectly matches the Scikit-Learn result, proving that both approaches arrive at the same mathematical "best fit."
