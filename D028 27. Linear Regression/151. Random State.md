# Fair Model Comparison

When you are tuning a model—for example, deciding between a Random Forest and an XGBoost—you need an "apples-to-apples" comparison.

If the data split is different for every model, you won't know if XGBoost performed better because it’s a better algorithm, or because it just happened to get "easier" data in its training set.

Keeping the random_state consistent ensures both models are judged on the exact same training and testing data.
