# Implementation of Linear Regression using Ordinary Least Squares (OLS)

In linear regression, our primary objective is to find the **best fit line** that minimizes the error between predicted and actual data points. While **Gradient Descent** uses an iterative optimization process to reach the global minima, **Ordinary Least Squares (OLS)** provides a closed-form mathematical solution to calculate the model parameters directly.

---

## 1. The Core Concept of OLS

The OLS technique identifies the optimal **intercept (β₀)** and **coefficient (β₁)** by minimizing the sum of the squares of the vertical deviations between each data point and the fitted line.

### The Linear Equation

For a simple linear regression model, the hypothesis is:


$$ŷ = β₀ + β₁x₁$$

### The Objective Function

We aim to minimize the residual sum of squares (RSS), represented here as $S$:


$$S(β₀, β₁) = (1/n) Σ (yᵢ - (β₀ + β₁xᵢ))²$$

Where:

* **yᵢ**: The actual truth value.
* **ŷ (or hθ(x))**: The predicted value ($β₀ + β₁xᵢ$).
* **n**: Total number of data points.

---

## 2. Deriving the OLS Formulas

To find the values of $β₀$ and $β₁$ that minimize the error, we take the partial derivatives of the cost function with respect to each parameter and set them to zero.

### Step 1: Derivative with respect to β₀

Taking the partial derivative ($∂S/∂β₀$):


$$-(2/n) Σ (yᵢ - β₀ - β₁xᵢ) = 0$$

By simplifying this equation (moving constants and distributing the summation), we arrive at the formula for the **Intercept**:


$$β₀ = ȳ - β₁x̄$$

> **Key Terminology:**
> * **ȳ (y-bar)**: The mean (average) of all dependent variable values ($Σyᵢ / n$).
> * **x̄ (x-bar)**: The mean (average) of all independent variable values ($Σxᵢ / n$).
> 
> 

### Step 2: Derivative with respect to β₁

Taking the partial derivative ($∂S/∂β₁$):


$$-(2/n) Σ [(yᵢ - β₀ - β₁xᵢ) · xᵢ] = 0$$

By substituting the value of $β₀$ into this equation and rearranging the terms to isolate $β₁$, we derive the formula for the **Slope/Coefficient**:


$$β₁ = [Σ(xᵢ - x̄)(yᵢ - ȳ)] / [Σ(xᵢ - x̄)²]$$

*(Note: The transcript derivation simplifies the logical flow toward the relationship between the deviations of x and y from their respective means.)*

---

## 3. Comparison of Techniques

| Feature | Gradient Descent | Ordinary Least Squares (OLS) |
| --- | --- | --- |
| **Method** | Iterative Optimization | Analytical/Mathematical Formula |
| **Complexity** | Efficient for very large datasets | Computationally expensive for many features |
| **Parameters** | Requires Learning Rate (α) and Epochs | No hyperparameters needed |
| **Goal** | Reach Global Minima of Loss Function | Minimize Sum of Squared Errors directly |

---

## 4. Practical Implementation Steps

To calculate the best fit line manually using OLS, follow these steps:

1. **Calculate Means**: Find the average of your $x$ values ($x̄$) and $y$ values ($ȳ$).
2. **Calculate Deviations**: For every data point, find $(xᵢ - x̄)$ and $(yᵢ - ȳ)$.
3. **Find β₁ (Slope)**: Use the ratio of the covariance of $x$ and $y$ to the variance of $x$.
4. **Find β₀ (Intercept)**: Substitute $β₁$, $x̄$, and $ȳ$ into the formula $β₀ = ȳ - β₁x̄$.

Once you have $β₀$ and $β₁$, you have defined your best fit line and can begin making predictions.
