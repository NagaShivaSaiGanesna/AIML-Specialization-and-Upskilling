# Feature Scaling & Gradient Descent — The Math That Makes It Click

---

## The Setup: A Tiny House Price Problem

We want to predict house price using two features:
- **x₁ = Square Footage** → ranges from **500 to 5000**
- **x₂ = Bedrooms** → ranges from **1 to 5**

Our model: `ŷ = θ₀ + θ₁·x₁ + θ₂·x₂`

We'll ignore θ₀ (bias) to keep it clean. So we're fitting `ŷ = θ₁·x₁ + θ₂·x₂`.

---

## Part 1: What Is the Cost Function Doing Geometrically?

The cost function J(θ) measures how wrong our predictions are:

```
J(θ₁, θ₂) = (1/2m) · Σ (ŷᵢ - yᵢ)²
```

When we **plot J as a surface** over (θ₁, θ₂), we get a bowl shape.

**The shape of that bowl depends entirely on the scale of your features.**

---

## Part 2: The Gradient — What Direction Do We Step?

The gradient tells us the slope of J at our current (θ₁, θ₂):

```
∂J/∂θ₁ = (1/m) · Σ (ŷᵢ - yᵢ) · x₁ᵢ
∂J/∂θ₂ = (1/m) · Σ (ŷᵢ - yᵢ) · x₂ᵢ
```

**Notice:** x₁ multiplies the gradient for θ₁, and x₂ multiplies the gradient for θ₂.

If x₁ is ~1000x bigger than x₂, then:
- The gradient w.r.t. θ₁ is ~1000x **larger**
- The gradient w.r.t. θ₂ is ~1000x **smaller**

This is the root cause of all the trouble.

---

## Part 3: Numerical Example — WITHOUT Scaling

### Sample Data (3 houses)

| House | Sq Ft (x₁) | Bedrooms (x₂) | Price y ($k) |
|-------|-----------|---------------|-------------|
| 1     | 2000      | 3             | 400         |
| 2     | 3000      | 4             | 600         |
| 3     | 1500      | 2             | 300         |

**Start:** θ₁ = 0, θ₂ = 0 (wild initial guess, all predictions = 0)

**Learning rate:** α = 0.0001

---

### Iteration 1 Walkthrough

**Predictions with θ₁=0, θ₂=0:**
```
ŷ₁ = 0·2000 + 0·3 = 0    →  error = 0 - 400 = -400
ŷ₂ = 0·3000 + 0·4 = 0    →  error = 0 - 600 = -600
ŷ₃ = 0·1500 + 0·2 = 0    →  error = 0 - 300 = -300
```

**Compute gradients:**
```
∂J/∂θ₁ = (1/3) · [(-400)·2000 + (-600)·3000 + (-300)·1500]
        = (1/3) · [-800,000 + -1,800,000 + -450,000]
        = (1/3) · (-3,050,000)
        = -1,016,667   ← ENORMOUS

∂J/∂θ₂ = (1/3) · [(-400)·3 + (-600)·4 + (-300)·2]
        = (1/3) · [-1,200 + -2,400 + -600]
        = (1/3) · (-4,200)
        = -1,400       ← small
```

**Update step (α = 0.0001):**
```
θ₁_new = 0 - 0.0001 · (-1,016,667) = +101.67
θ₂_new = 0 - 0.0001 · (-1,400)     = +0.14
```

---

### Iteration 2 Walkthrough

**Predictions with θ₁=101.67, θ₂=0.14:**
```
ŷ₁ = 101.67·2000 + 0.14·3 = 203,340 + 0.42 ≈ 203,340
     error = 203,340 - 400 = +202,940   ← OVERSHOT MASSIVELY
ŷ₂ = 101.67·3000 + 0.14·4 = 305,010 + 0.56 ≈ 305,011
     error = 305,011 - 600 = +304,411
ŷ₃ = 101.67·1500 + 0.14·2 = 152,505 + 0.28 ≈ 152,505
     error = 152,505 - 300 = +152,205
```

**Compute gradient:**
```
∂J/∂θ₁ = (1/3) · [(202940)·2000 + (304411)·3000 + (152205)·1500]
        = (1/3) · [405,880,000 + 913,233,000 + 228,307,500]
        ≈ +515,807,000  ← now a POSITIVE GIANT
```

**Update step:**
```
θ₁_new = 101.67 - 0.0001 · 515,807,000 ≈ 101.67 - 51,581 ≈ -51,479
```

### What Just Happened?

```
θ₁ trajectory:
  Step 0: θ₁ =       0
  Step 1: θ₁ = +101.67   (overshot past optimum)
  Step 2: θ₁ = -51,479   (MASSIVELY overshot the other way)
  Step 3: → +thousands   (explodes further)
```

**This is gradient explosion / oscillation.** The large x₁ values amplify the gradient so much that each step wildly overshoots. θ₁ bounces back and forth across the valley like a ping-pong ball — getting *worse*, not better.

Meanwhile, θ₂ barely moves (its gradient was only ~1400 vs ~1,000,000+).

---

## Part 4: The Fix — Standardization (Z-score)

Transform each feature so it has **mean = 0** and **std = 1**:

```
x'ᵢ = (xᵢ - μ) / σ
```

**For x₁ (Sq Ft):**
```
μ₁ = (2000 + 3000 + 1500) / 3 = 2167
σ₁ = std([2000, 3000, 1500]) ≈ 629

x'₁ for house 1: (2000 - 2167) / 629 = -0.27
x'₁ for house 2: (3000 - 2167) / 629 = +1.32
x'₁ for house 3: (1500 - 2167) / 629 = -1.06
```

**For x₂ (Bedrooms):**
```
μ₂ = (3 + 4 + 2) / 3 = 3
σ₂ = std([3, 4, 2]) ≈ 1

x'₂ for house 1: (3 - 3) / 1 = 0.0
x'₂ for house 2: (4 - 3) / 1 = +1.0
x'₂ for house 3: (2 - 3) / 1 = -1.0
```

**After scaling, all features live in roughly [-2, +2].**

---

## Part 5: Gradient Descent WITH Scaling

**Start:** θ₁ = 0, θ₂ = 0, **Learning rate: α = 0.1** (can be much larger now!)

### Iteration 1 (scaled data)

**Scaled data:**
| House | x'₁   | x'₂  | y   |
|-------|--------|------|-----|
| 1     | -0.27  | 0.0  | 400 |
| 2     | +1.32  | +1.0 | 600 |
| 3     | -1.06  | -1.0 | 300 |

**Predictions (θ₁=0, θ₂=0):** all predictions = 0, same errors as before.

**Compute gradients:**
```
∂J/∂θ₁ = (1/3) · [(-400)·(-0.27) + (-600)·(1.32) + (-300)·(-1.06)]
        = (1/3) · [108 + (-792) + 318]
        = (1/3) · (-366)
        = -122     ← SAME ORDER OF MAGNITUDE as...

∂J/∂θ₂ = (1/3) · [(-400)·0.0 + (-600)·1.0 + (-300)·(-1.0)]
        = (1/3) · [0 + (-600) + 300]
        = (1/3) · (-300)
        = -100     ← ...this!
```

**Update (α = 0.1):**
```
θ₁_new = 0 - 0.1 · (-122) = +12.2
θ₂_new = 0 - 0.1 · (-100) = +10.0
```

**Both parameters update in a balanced way.** No explosion. No oscillation.

### Iteration 2 (scaled data)

Both θ₁ and θ₂ are now moving meaningfully toward the minimum. The errors shrink. Gradients shrink. The steps get smaller. It converges cleanly.

---

## Part 6: Why Does This Make the Bowl Round?

The cost function surface J(θ) is approximately:

```
J(θ) ∝ θ₁²·Var(x₁) + θ₂²·Var(x₂)
```

- Var(x₁) (sq ft) ≈ 629² ≈ 395,000  → the bowl is VERY steep along θ₁
- Var(x₂) (bedrooms) ≈ 1² = 1       → the bowl is VERY flat along θ₂

This creates a **long, thin elliptical trough**. Gradient descent can only move perpendicular to the contour lines — so it zig-zags across the narrow axis instead of heading straight for the bottom.

After standardization:
- Var(x'₁) = 1
- Var(x'₂) = 1

Now the bowl is **perfectly circular**. The gradient points directly at the minimum. Gradient descent takes a straight shot.

```
Without Scaling:              With Scaling:

  θ₂                           θ₂
  |  ___________                |     ___
  | /           \               |    /   \
  |/ zig  zig    \              |   / → ↓ \
  |    zag  →→ ★ |              |  |   ★   |
  |\             /              |   \     /
  | \___________/               |    \___/
  |________________________     |________________
                         θ₁                    θ₁

  Oscillates wildly            Converges directly
```

## Part 7: Normalization vs Standardization

| Method | Formula | Range | Use When |
|--------|---------|-------|---------|
| **Min-Max Normalization** | x' = (x - min) / (max - min) | [0, 1] | No outliers, bounded data |
| **Standardization (Z-score)** | x' = (x - μ) / σ | ~[-3, 3] | Outliers present, normally distributed data |

**Standardization is almost always the safer default.**

---

## Part 8: Critical Rule — Scale At Inference Too!

When your model is trained and you want to predict a new house:

```python
# WRONG: feeding raw values to a model trained on scaled data
new_house = [2500, 3]
prediction = model.predict(new_house)  # garbage output!

# CORRECT: apply the SAME scaling parameters from training
x1_scaled = (2500 - 2167) / 629   # use training μ and σ
x2_scaled = (3 - 3) / 1
prediction = model.predict([x1_scaled, x2_scaled])  # correct!
```

**Never refit the scaler on test/new data.** Use the mean and std from training only.

---

## TL;DR — The Core Intuition

| Concept | Without Scaling | With Scaling |
|--------|----------------|-------------|
| Gradient magnitudes | Wildly different (1000x gap) | Similar (~same order) |
| Bowl shape | Long thin ellipse (trough) | Circular |
| Gradient descent path | Zig-zag oscillation | Straight to minimum |
| Learning rate needed | Tiny (or it explodes) | Can be much larger |
| Convergence | Slow / diverges | Fast and stable |

**The one-line intuition:**
> The gradient is multiplied by the feature value. Huge features → huge gradients → huge steps → explosion. Scaling features makes all gradients comparable, so every parameter learns at the same pace.

---

*Reference note: θ₁ and θ₂ are learned weights for each feature. J(θ) is Mean Squared Error. α is the learning rate. All examples above use m=3 data points for simplicity.*
