# Cost Functions and Gradient Descent in Linear Regression

In Simple Linear Regression, our goal is to find the **best fit line**. To do this, we need a mathematical way to measure how "wrong" our line is and a systematic way to improve it. This is where the **Cost Function** and **Gradient Descent** come into play.

---

## 1. The Cost Function: Mean Squared Error (MSE)

The **Cost Function** measures the error between the predicted values and the actual truth values. For linear regression, we use **Mean Squared Error (MSE)**.

### Mathematical Representation

The cost function is denoted as J(θ₀, θ₁):

**J(θ₀, θ₁) = (1 / 2m) * Σ [ (hθ(x⁽ⁱ⁾) - y⁽ⁱ⁾)² ]**

| Variable | Description |
| --- | --- |
| **J(θ₀, θ₁)** | The Cost Function value (the "error score"). |
| **m** | The total number of training examples (data points). |
| **hθ(x⁽ⁱ⁾)** | The **Predicted Value** for the i-th input (the point on the line). |
| **y⁽ⁱ⁾** | The **Actual Value** (the truth point). |
| **hθ(x⁽ⁱ⁾) - y⁽ⁱ⁾** | The **Residual** or error for a single point. |

### Why Square the Error?

1. **Positivity:** Squaring ensures that positive and negative errors don't cancel each other out.
2. **Penalty:** It penalizes larger errors more heavily than smaller ones, forcing the model to prioritize reducing significant outliers.

---

## 2. The Goal: Minimizing the Cost

Our objective is to find the values of **θ₀ (Intercept)** and **θ₁ (Slope)** that result in the smallest possible value for **J(θ₀, θ₁)**.

**Minimize J(θ₀, θ₁)**

To visualize this, imagine we simplify the problem by setting the intercept **θ₀ = 0** (meaning the line passes through the origin). We are then only left with finding the best slope **θ₁**.

---

## 3. Visualizing Gradient Descent

When we plot the relationship between the slope (**θ₁**) and the resulting error (**J**), we get a U-shaped curve known as a **Convex Function**.

### The Gradient Descent Curve

* **Global Minima:** The lowest point on the curve. At this point, the cost function is at its minimum, and we have found our **Best Fit Line**.
* **Gradient:** The slope of the curve at any given point.

### Walkthrough Example:

Imagine a dataset with points (1,1), (2,2), and (3,3).

1. **If we choose θ₁ = 1:**
* Predictions match truth exactly (1=1, 2=2, 3=3).
* **Error = 0**. This is our **Global Minima**.


2. **If we choose θ₁ = 0.5:**
* Predictions are (0.5, 1.0, 1.5).
* **Error > 0**. The line is too shallow.


3. **If we choose θ₁ = 0:**
* Predictions are all (0, 0, 0).
* **Error is high**. The line is horizontal.



By plotting these errors, we see the "valley" form. Gradient Descent is the process of "stepping down" into this valley to find the bottom.

---

## 4. Key Differences in Learning Approaches

| Concept | Model-Based (Generalization) | Instance-Based (Memorization) |
| --- | --- | --- |
| **Mechanism** | Uses Gradient Descent to find θ₀, θ₁. | Stores data and looks at neighbors. |
| **Storage** | Only needs to store θ₀ and θ₁. | Needs to store the whole dataset. |
| **Prediction** | Instant (plugs x into the line equation). | Slow (calculates distance to neighbors). |

---

## 5. What’s Next: The Convergence Algorithm

We cannot simply guess different values of **θ₁** forever. We need a "Convergence Algorithm" to automatically decide:

1. Which **direction** to move (should we increase or decrease the slope?).
2. How **big** of a step to take (the **Learning Rate**, denoted as α).
