# Predicting Economic Index Price: Multiple Linear Regression

This guide details the end-to-end implementation of a **Multiple Linear Regression** model to predict the **Economic Index Price** based on two key financial indicators: **Interest Rate** and **Unemployment Rate**.

---

## 1. Project Overview & Data Understanding

In multiple linear regression, we use two or more independent variables to predict a single continuous dependent variable.

### Key Features

* **Independent Variables (X):** 1.  **Interest Rate:** The percentage at which banks lend money.
2.  **Unemployment Rate:** The percentage of the total workforce that is unemployed.
* **Dependent Variable (y):** 1.  **Index Price:** A relative measure of price changes over time.

### Correlation Intuition

* **Interest Rate vs. Index Price:** Typically shows a **positive correlation** (as rates rise, the index often rises in this specific dataset).
* **Unemployment Rate vs. Index Price:** Typically shows an **inverse (negative) correlation** (as unemployment rises, the index price tends to fall).

## 3. Model Training & Validation

### Cross-Validation Strategy

To ensure the model is robust and not just "lucky" with a specific train-test split, we implement **Cross-Validation** using `cross_val_score`.

**How K-Fold Cross-Validation Works (CV=5):**

1. The training data is divided into 5 equal segments (folds).
2. The model runs 5 experiments. In each experiment, a different fold acts as the **Validation Set**, while the other 4 folds act as the **Training Set**.
3. We calculate the **Negative Mean Squared Error (MSE)** for each run.
4. The final performance is the average (mean) of these 5 scores.

### Standardization

Because multiple features (Interest Rate and Unemployment) may have different scales, we apply **Standard Scaling** to transform them into a distribution with a mean (μ) of 0 and a standard deviation (σ) of 1.

$$z = \frac{x_i - \mu}{\sigma}$$

## 4. Evaluation Metrics

We evaluate the model using traditional regression metrics:

| Metric | Purpose |
| --- | --- |
| **MSE / MAE** | Measures the average magnitude of the errors. |
| **R² Score** | Measures how much of the variance in the index price is explained by our features. |
| **Adjusted R²** | Penalizes the addition of independent variables that do not improve the model. |

## 5. Testing Assumptions (Residual Analysis)

A high-quality regression model must satisfy several statistical assumptions:

### Assumption 1: Linear Relationship

Plotting `y_test` against `y_pred` should reveal a clear linear trend.

### Assumption 2: Normal Distribution of Residuals

The **Residuals** (errors = $y_{test} - y_{pred}$) should follow a **Normal Distribution** (Bell Curve). This is checked using a **KDE (Kernel Density Estimate) Plot**.

### Assumption 3: Homoscedasticity (Uniform Distribution)

A scatter plot of **Predictions** vs. **Residuals** should show no discernible pattern. The points should be spread uniformly. If a "funnel" or "curve" pattern appears, the model may be missing a non-linear relationship.
