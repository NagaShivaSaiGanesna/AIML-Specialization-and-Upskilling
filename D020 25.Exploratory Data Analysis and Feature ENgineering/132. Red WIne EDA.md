# Exploratory Data Analysis (EDA): The Red Wine Dataset

Welcome to the foundation of data science! Before applying machine learning models, we must thoroughly understand our data. **Exploratory Data Analysis (EDA)** is the process of investigating a dataset to discover patterns, spot anomalies, test hypotheses, and check assumptions using summary statistics and graphical representations.

In this guide, we will walk through a complete EDA pipeline using the **Red Wine Quality Dataset** from the UCI Machine Learning Repository.

---

## 1. Understanding the Red Wine Dataset

The dataset records the physicochemical and sensory attributes of Portuguese "Vinho Verde" red wine.

* **Input Features (X):** 11 numeric properties representing the chemical makeup of the wine (e.g., `fixed acidity`, `volatile acidity`, `citric acid`, `residual sugar`, `chlorides`, `free sulfur dioxide`, `total sulfur dioxide`, `density`, `pH`, `sulfates`, `alcohol`).
* **Target Variable (y):** `quality`. This is a sensory score (usually ranging from 3 to 8) assigned by wine experts. The higher the score, the better the quality.

---

## 2. Initial Data Inspection

Once the dataset is loaded into a Pandas DataFrame using `pd.read_csv()`, our first step is to get a high-level overview of the data structure.

### Checking the Summary (`df.info()`)

The `df.info()` method provides a concise summary of the DataFrame. It tells us the total number of rows, the column names, the data types (e.g., `float64`, `int64`), and the count of **non-null** values. This immediately helps us identify if columns have mixed data types or missing values.

### Descriptive Statistics (`df.describe()`)

To understand the mathematical distribution of our numerical features, we use `df.describe()`. This generates a statistical summary that includes:

* **Count:** Total number of non-empty rows.
* **Mean (μ):** The average value.
* **Standard Deviation (σ):** How spread out the data is from the mean.
* **Min & Max:** The lowest and highest values.
* **Percentiles (25th, 50th, 75th):** The 50th percentile is the **median**. Comparing the mean and median gives an early indication of data skewness.

### Shape and Columns (`df.shape`, `df.columns`)

* `df.shape` returns a tuple (e.g., `(1599, 12)`), indicating the dataset has 1,599 records and 12 columns.
* `df.columns` returns a list of all feature names, which is handy when iterating through the dataset.

---

## 3. Data Cleaning: Missing Values and Duplicates

A machine learning model is only as good as the data it trains on. We must ensure the data is clean.

### Checking for Missing Values

We use `df.isnull().sum()` to calculate the total number of missing (NaN) values in each column. If missing values exist, we must handle them using imputation techniques (mean, median, or mode replacement). Fortunately, the Red Wine dataset is typically complete, returning 0 missing values.

### Removing Duplicate Records

Duplicate rows can skew our distributions and cause our model to overfit by memorizing repeated patterns.

1. **Identify:** `df.duplicated()` returns a boolean series indicating which rows are exact duplicates.
2. **Remove:** We use `df.drop_drop_duplicates(inplace=True)`. The `inplace=True` parameter ensures the changes are permanently applied to our existing DataFrame without needing to create a new variable.

*Note: In our sample, dropping duplicates reduced the dataset from 1599 to roughly 1359 records.*

---

## 4. Target Variable Analysis

Before analyzing relationships between features, we must analyze the target variable itself (`quality`).

By executing `df['quality'].unique()`, we see the distinct quality scores (e.g., 3, 4, 5, 6, 7, 8). To see how many wines fall into each category, we use `df['quality'].value_counts()`.

### The Imbalanced Dataset Problem

You will likely notice that scores like 5 and 6 have hundreds of records, while extreme scores like 3 or 8 have very few. This is an **Imbalanced Dataset**. In a real-world scenario, this imbalance means our model will be excellent at predicting average wines but poor at predicting exceptionally good or bad ones. Later in the machine learning pipeline, techniques like SMOTE (Synthetic Minority Over-sampling Technique) are used to fix this.

---

## 5. Correlation & Multivariate Analysis

We need to understand how our features relate to one another and, most importantly, how they relate to our target variable (`quality`). We measure this using **Pearson Correlation**, which returns a value between -1 (perfect negative correlation) and 1 (perfect positive correlation).

### Visualizing with a Heatmap

Looking at a massive matrix of correlation numbers is difficult. Instead, we use the `seaborn` library to create a **Heatmap**.

```python
import matplotlib.pyplot as plt
import seaborn as sns

# Set the figure size to prevent overlapping
plt.figure(figsize=(10, 6))

# Plot the heatmap
sns.heatmap(df.corr(), annot=True)
plt.show()

```

* `df.corr()`: Calculates the correlation matrix.
* `annot=True`: An essential parameter that annotates (prints) the actual correlation numbers inside the colored boxes on the chart.
* `plt.figure(figsize=(10, 6))`: Adjusts the dimensions so the text remains readable.

## 6. Data Visualization Toolkit

Visualization is the core of EDA. Here is a summary of the plots used to uncover patterns:

| Plot Type | Seaborn Command | Primary Purpose in EDA |
| --- | --- | --- |
| **Bar Plot** | `sns.countplot()` / `.plot(kind='bar')` | Visualizing the frequency of categorical/discrete values (e.g., checking the class imbalance of `quality`). |
| **Histogram / KDE** | `sns.histplot(kde=True)` | Viewing the distribution of a single numerical feature. `kde=True` overlays a Probability Density Function line. |
| **Pair Plot** | `sns.pairplot()` | A grid showing scatter plots for every combination of features, useful for spotting overarching linear relationships or clusters. *(Note: Slow on large datasets).* |
| **Box Plot** | `sns.catplot(kind='box')` | Comparing a numerical feature (like `alcohol`) across different categories (like `quality`). Excellent for identifying outliers. |
| **Scatter Plot** | `sns.scatterplot()` | Checking the relationship between two specific numeric features. Using the `hue` parameter allows us to color the dots based on the target variable. |

### Example: Scatter Plot with Hue

By plotting `alcohol` against `pH` and coloring the points by `quality`, we can visually assess if higher alcohol and lower pH naturally cluster around higher quality scores.

```python
sns.scatterplot(x='alcohol', y='pH', hue='quality', data=df)

```
