## Step 2 — Train each model (1 epoch each)

Each model is just standard logistic regression. Model equation:

$$P = \sigma(b_0 + b_1 x_1 + b_2 x_2)$$

**All models start with b₀=0, b₁=0, b₂=0 so z=0 and P=0.5 for everyone initially.**

---

## Model M1 — "Is this student a Fail?"

Target y = [1, 1, 0, 0, 0, 0]

### Forward pass

Since all weights = 0, z = 0, P = 0.5 for everyone.

| Student | x₁ | x₂ | z | P | y₁ | P−y |
|---|---|---|---|---|---|---|
| 1 | 2 | 5 | 0 | 0.5 | 1 | −0.5 |
| 2 | 3 | 6 | 0 | 0.5 | 1 | −0.5 |
| 3 | 5 | 7 | 0 | 0.5 | 0 | +0.5 |
| 4 | 6 | 8 | 0 | 0.5 | 0 | +0.5 |
| 5 | 2 | 3 | 0 | 0.5 | 0 | +0.5 |
| 6 | 3 | 4 | 0 | 0.5 | 0 | +0.5 |
| **Sum** | | | | | | **1.0** |

### Cost

| Student | y₁ | P | Cost |
|---|---|---|---|
| 1 | 1 | 0.5 | −log(0.5) = 0.693 |
| 2 | 1 | 0.5 | −log(0.5) = 0.693 |
| 3 | 0 | 0.5 | −log(0.5) = 0.693 |
| 4 | 0 | 0.5 | −log(0.5) = 0.693 |
| 5 | 0 | 0.5 | −log(0.5) = 0.693 |
| 6 | 0 | 0.5 | −log(0.5) = 0.693 |

$$J_{M1} = \frac{6 \times 0.693}{6} = \mathbf{0.693}$$

### Gradients

$$\frac{\partial J}{\partial b_0} = \frac{1}{6}\sum(P-y) = \frac{1.0}{6} = +0.1667$$

$$\frac{\partial J}{\partial b_1} = \frac{1}{6}\sum(P-y)\times x_1 = \frac{(-0.5)(2)+(-0.5)(3)+(0.5)(5)+(0.5)(6)+(0.5)(2)+(0.5)(3)}{6}$$

$$= \frac{-1-1.5+2.5+3+1+1.5}{6} = \frac{5.5}{6} = +0.9167$$

$$\frac{\partial J}{\partial b_2} = \frac{1}{6}\sum(P-y)\times x_2 = \frac{(-0.5)(5)+(-0.5)(6)+(0.5)(7)+(0.5)(8)+(0.5)(3)+(0.5)(4)}{6}$$

$$= \frac{-2.5-3+3.5+4+1.5+2}{6} = \frac{5.5}{6} = +0.9167$$

### Weight update

$$b_0 = 0 - 0.1 \times 0.1667 = \mathbf{-0.0167}$$
$$b_1 = 0 - 0.1 \times 0.9167 = \mathbf{-0.0917}$$
$$b_2 = 0 - 0.1 \times 0.9167 = \mathbf{-0.0917}$$

## Model M2 — "Is this student a Pass?"

### Forward pass (all weights=0, P=0.5 still)

|---|---|---|---|---|---|

| 6 | 3 | 4 | 0.5 | 0 | +0.5 |
| **Sum** | | | | | **1.0** |

### Cost

$$J_{M2} = \mathbf{0.693}$$ (same as M1 — all P=0.5)

### Gradients

$$\frac{\partial J}{\partial b_0} = \frac{1.0}{6} = +0.1667$$

$$\frac{\partial J}{\partial b_1} = \frac{(0.5)(2)+(0.5)(3)+(-0.5)(5)+(-0.5)(6)+(0.5)(2)+(0.5)(3)}{6}$$

$$= \frac{1+1.5-2.5-3+1+1.5}{6} = \frac{-0.5}{6} = \mathbf{-0.0833}$$

$$\frac{\partial J}{\partial b_2} = \frac{(0.5)(5)+(0.5)(6)+(-0.5)(7)+(-0.5)(8)+(0.5)(3)+(0.5)(4)}{6}$$

### Weight update

$$b_0 = 0 - 0.1 \times 0.1667 = \mathbf{-0.0167}$$
$$b_1 = 0 - 0.1 \times (-0.0833) = \mathbf{+0.0083}$$
$$b_2 = 0 - 0.1 \times 0.25 = \mathbf{-0.025}$$

### Cost

$$J_{M3} = \mathbf{0.693}$$

### Gradients

$$\frac{\partial J}{\partial b_0} = \frac{1.0}{6} = +0.1667$$

$$\frac{\partial J}{\partial b_1} = \frac{(0.5)(2)+(0.5)(3)+(0.5)(5)+(0.5)(6)+(-0.5)(2)+(-0.5)(3)}{6}$$

$$= \frac{1+1.5+2.5+3-1-1.5}{6} = \frac{5.5}{6} = \mathbf{+0.9167}$$

$$b_0 = 0 - 0.1 \times 0.1667 = \mathbf{-0.0167}$$
$$b_1 = 0 - 0.1 \times 0.9167 = \mathbf{-0.0917}$$
$$b_2 = 0 - 0.1 \times 1.5833 = \mathbf{-0.1583}$$

## Step 3 — Prediction on a new student

**New student: x₁ = 4 study hrs, x₂ = 7 sleep hrs**

Pass each through the 3 updated models:

### M1 (Fail weights: b₀=−0.0167, b₁=−0.0917, b₂=−0.0917)

$$z = -0.0167 + (-0.0917)(4) + (-0.0917)(7) = -0.0167 - 0.3668 - 0.6419 = -1.0254$$

$$P_1 = \sigma(-1.0254) = \frac{1}{1+e^{1.0254}} = \frac{1}{1+2.788} = \mathbf{0.264}$$

### M2 (Pass weights: b₀=−0.0167, b₁=+0.0083, b₂=−0.025)

$$z = -0.0167 + (0.0083)(4) + (-0.025)(7) = -0.0167 + 0.0332 - 0.175 = -0.1585$$

$$P_2 = \sigma(-0.1585) = \frac{1}{1+e^{0.1585}} = \frac{1}{1+1.172} = \mathbf{0.461}$$

### M3 (Dropout weights: b₀=−0.0167, b₁=−0.0917, b₂=−0.1583)

$$z = -0.0167 + (-0.0917)(4) + (-0.1583)(7) = -0.0167 - 0.3668 - 1.1081 = -1.4916$$

$$P_3 = \sigma(-1.4916) = \frac{1}{1+e^{1.4916}} = \frac{1}{1+4.444} = \mathbf{0.184}$$
