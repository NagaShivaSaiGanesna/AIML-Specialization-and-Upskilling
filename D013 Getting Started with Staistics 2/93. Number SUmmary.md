# Five Number Summary and Outlier Detection

The **Five Number Summary** is a powerful statistical tool used to describe the distribution of a dataset. It is particularly useful for identifying **outliers**—data points that are significantly different from the rest of the observations.

---

## The Five Number Summary

These five values provide a snapshot of the data's range and concentration:

1. **Minimum:** The smallest value in the dataset (after removing outliers).
2. **First Quartile (Q1):** The 25th percentile (25% of data falls below this).
3. **Median (Q2):** The 50th percentile; the middle value of the dataset.
4. **Third Quartile (Q3):** The 75th percentile (75% of data falls below this).
5. **Maximum:** The largest value in the dataset (after removing outliers).

---

## Dealing with Outliers: The Interquartile Range (IQR) Method

To determine if a value is an "outlier," we use the **Interquartile Range (IQR)** to set boundaries called "fences."

### Key Formulas:

* **IQR:** Q3 - Q1
* **Lower Fence:** Q1 - 1.5 * IQR
* **Higher Fence:** Q3 + 1.5 * IQR

> **The Rule:** Any data point **greater than the Higher Fence** or **less than the Lower Fence** is considered an outlier.

---

## Step-by-Step Example

**Dataset:** 1, 2, 2, 2, 3, 3, 4, 5, 5, 5, 6, 6, 6, 6, 6, 7, 8, 8, 9, 27
*Sample Size (n) = 20*

### 1. Find Q1 (25th Percentile)

* **Position:** (25 / 100) * 20 = 5th position.
* **Value at 5th position:** **3**
* **Q1 = 3**

### 2. Find Q3 (75th Percentile)

* **Position:** (75 / 100) * 20 = 15th position.
* **Value at 15th position:** **7**
* **Q3 = 7**

### 3. Calculate IQR and Fences

* **IQR:** 7 - 3 = **4**
* **Lower Fence:** 3 - (1.5 * 4) = 3 - 6 = **-3**
* **Higher Fence:** 7 + (1.5 * 4) = 7 + 6 = **13**

### 4. Identify Outliers

Looking at our data, is any number > 13 or < -3?

* **27** is greater than 13. Therefore, **27 is an outlier** and should be removed for a clean summary.

---

## Final Five Number Summary (Cleaned Data)

After removing the outlier (27), our summary looks like this:

| Metric | Value |
| --- | --- |
| **Minimum** | 1 |
| **First Quartile (Q1)** | 3 |
| **Median** | 5 |
| **Third Quartile (Q3)** | 7 |
| **Maximum** | 9 |

---

## Visualizing with a Box Plot

The Five Number Summary is the direct foundation for a **Box Plot** (also known as a Box-and-Whisker Plot). This visualization allows you to see the spread and the outliers at a glance.

* **The Box:** Represents the IQR (from Q1 to Q3).
* **The Line in the Box:** Represents the Median.
* **The Whiskers:** Extend to the Minimum and Maximum values (within the fences).
* **The Dots:** Any points outside the whiskers are flagged as outliers.
