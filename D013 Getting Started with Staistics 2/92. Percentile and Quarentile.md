## Percentages, Percentiles, and Quartiles

In statistics, understanding the position of a data point relative to the rest of the dataset is crucial. While we often use averages, **Percentiles** and **Quartiles** provide a more detailed map of how data is distributed.

---

## Percentage vs. Percentile

It is common to confuse these two terms, but they represent very different concepts in data analysis.

### Percentage

A **Percentage** is a way to express a number as a fraction of 100. It focuses on a portion of a whole.

* **Formula:** (Count of specific items / Total items) * 100
* **Example:** In a list of numbers [1, 2, 3, 4, 5, 6], there are 3 odd numbers. The percentage of odd numbers is (3 / 6) * 100 = **50%**.

### Percentile

A **Percentile** is a value below which a certain percentage of observations in a distribution fall. It indicates the **relative standing** of a value.

* **Meaning:** If you are in the 99th percentile of an exam, it doesn't mean you scored 99%. It means you scored better than 99% of the people who took the test.

---

## How to Calculate Percentile Ranking

To find the percentile rank of a specific value (**x**) in a dataset, use the following formula:

**Percentile Rank of x = (Number of values below x / n) * 100**

*(Where **n** is the total sample size)*

### Example Calculation

**Dataset:** [2, 2, 3, 4, 5, 5, 6, 7, 8, 8, 8, 9, 9, 10] (**n = 14**)
**Goal:** Find the percentile rank for the value **9**.

1. **Count values below 9:** There are 11 values smaller than 9.
2. **Apply formula:** (11 / 14) * 100 = 78.57
3. **Result:** The value 9 is at the **78.57 percentile**. This means 78.57% of the entire distribution is less than 9.

---

## Finding a Value from a Percentile

If you want to find which specific value corresponds to a given percentile (e.g., "What is the 25th percentile value?"), use this formula to find the index (**i**):

**i = (Percentile / 100) * (n + 1)**

### Example Calculation

**Goal:** Find the 25th percentile value of the dataset above (**n = 14**).

1. **Calculate Index:** (25 / 100) * (14 + 1) = 0.25 * 15 = **3.75**
2. **Handling Fractions:** Since 3.75 is between index 3 and 4, take the values at the 3rd and 4th positions and find their average.
3. **Result:** (3 + 4) / 2 = **3.5**. The 25th percentile is 3.5.

---

## Quartiles

**Quartiles** divide a ranked dataset into four equal parts. They are specific "milestone" percentiles.

| Quartile | Percentile Equivalent | Description |
| --- | --- | --- |
| **Q1 (First Quartile)** | 25th Percentile | The lower quartile; 25% of data falls below this. |
| **Q2 (Second Quartile)** | 50th Percentile | The **Median**; it splits the data exactly in half. |
| **Q3 (Third Quartile)** | 75th Percentile | The upper quartile; 75% of data falls below this. |

### Summary Comparison

| Feature | Percentage | Percentile |
| --- | --- | --- |
| **Definition** | Rate per hundred. | Positional standing in a group. |
| **Basis** | Dependent on the individual value. | Dependent on the values of the whole group. |
| **Range** | 0 to 100. | 0 to 100. |
