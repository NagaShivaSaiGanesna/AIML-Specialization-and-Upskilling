# Exploratory Data Analysis: Five-Number Summary and Box Plots in Python

This guide explores the statistical foundation of the **Five-Number Summary** and demonstrates how to implement **Box Plots** using Python's `numpy` and `seaborn` libraries to identify data distribution and outliers.

---

## 1. Understanding the Five-Number Summary

The Five-Number Summary is a descriptive statistic that provides a snapshot of the distribution of a dataset. It consists of five specific values that divide the data into quartiles.

### The Components

* **Minimum:** The lowest value in the dataset (excluding outliers).
* **First Quartile (Q1):** The **25th percentile**; 25% of the data falls below this value.
* **Median (Q2):** The **50th percentile**; the middle value of the dataset.
* **Third Quartile (Q3):** The **75th percentile**; 75% of the data falls below this value.
* **Maximum:** The highest value in the dataset (excluding outliers).

### Implementation with NumPy

To calculate these values in Python, we use the `numpy.quantile` function. By passing a list of percentages (0, 0.25, 0.50, 0.75, and 1.0), we can extract all five values simultaneously.

```python
import numpy as np

marks = [45, 32, 56, 75, 89, 54, 32, 89, 90, 87, 67, 54, 45, 98, 99, 67, 74]

# Calculating the Five-Number Summary
minimum, q1, median, q3, maximum = np.quantile(marks, [0, 0.25, 0.5, 0.75, 1.0])

```

## 2. Interquartile Range (IQR) and Outlier Detection

Before plotting, we must mathematically define what constitutes an "outlier." We do this using the **Interquartile Range (IQR)**.

### Mathematical Formulas

The IQR represents the distance between the 75th and 25th percentiles. We then establish "fences" (bounds). Any data point outside these fences is statistically flagged as an outlier.

| Metric | Formula |
| --- | --- |
| **Interquartile Range (IQR)** | IQR = Q3 - Q1 |
| **Lower Fence** | Lower Fence = Q1 - 1.5 × IQR |
| **Higher Fence** | Higher Fence = Q3 + 1.5 × IQR |

### Logic for Outliers

* **Lower Outlier:** Any value < Lower Fence.
* **Upper Outlier:** Any value > Higher Fence.

## 3. Constructing Box Plots with Seaborn

A **Box Plot** (or Box-and-Whisker Plot) is the visual representation of the Five-Number Summary. While we can calculate fences manually, Python libraries like `seaborn` automate this process.

### Basic Box Plot

```python
import seaborn as sns
import matplotlib.pyplot as plt

# Generating a basic box plot
sns.boxplot(marks)
plt.show()

```

### Visualizing Outliers

When a dataset contains extreme values, the box plot adapts. The "whiskers" of the plot typically extend to the Lower and Higher Fences, and any data points beyond those lines are plotted as individual dots.

**Example with Outliers:**
If we add extreme values like `-100` or `170` to our `marks` list, the `sns.boxplot` function will automatically:

1. Recalculate the quartiles.
2. Determine the new fences.
3. Render the extreme values as isolated points (dots) outside the whiskers.

## 4. Summary Table: Percentiles vs. Terms

To keep your terminology sharp, refer to this mapping of percentiles to their statistical names:

| Percentile | Statistical Term | Box Plot Element |
| --- | --- | --- |
| 0th | Minimum | Bottom Whisker Limit |
| 25th | First Quartile (Q1) | Bottom of Box |
| 50th | Median | Line inside Box |
| 75th | Third Quartile (Q3) | Top of Box |
| 100th | Maximum | Top Whisker Limit |
