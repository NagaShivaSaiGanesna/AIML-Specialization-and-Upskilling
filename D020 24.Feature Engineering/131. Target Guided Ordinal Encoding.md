# Target Guided Ordinal Encoding

This guide explores **Target Guided Ordinal Encoding**, an advanced feature engineering technique used to convert categorical variables into numerical values by leveraging their relationship with the target variable.

---

## 1. What is Target Guided Ordinal Encoding?

In standard encoding techniques (like One-Hot or Label Encoding), we transform categorical data based solely on the categories themselves. **Target Guided Ordinal Encoding** takes a smarter approach: it assigns a numerical value to a category based on the **mean or median** of the target variable for that specific category.

### Why Use It?

* **Handles High Cardinality:** If a feature has hundreds of unique categories (e.g., ZIP codes or cities), One-Hot Encoding will create hundreds of new columns, leading to the curse of dimensionality. This technique keeps the feature as a single column.
* **Preserves Predictive Power:** By linking the category directly to the target variable, the machine learning model immediately understands the importance or "weight" of each category relative to what it is trying to predict.

---

## 2. The Mathematical Intuition

Let's assume we are trying to predict the **Price** (target variable) of a house based on the **City** (categorical feature).

If our dataset contains two entries for New York and two for Paris, the algorithm calculates the mean (average) price for each city:

* **New York Prices:** 200, 180
* Mean (μ) = (200 + 180) / 2 = **190**


* **Paris Prices:** 320, 300
* Mean (μ) = (320 + 300) / 2 = **310**



We then replace the text "New York" with `190` and "Paris" with `310` throughout the entire dataset.

### Transformation Table

| Original City | Target Price |  | Encoded City Value | Target Price |
| --- | --- | --- | --- | --- |
| New York | 200 | ➡️ | **190** | 200 |
| London | 150 | ➡️ | **150** | 150 |
| Paris | 320 | ➡️ | **310** | 320 |
| New York | 180 | ➡️ | **190** | 180 |

---

## 3. Implementation in Python

We can implement this efficiently using the `pandas` library. We will use the `groupby()` function to calculate the means and the `map()` function to apply those means to our dataset.

### Step 1: Create the Dataset

```python
import pandas as pd

# Creating a sample dataset
data = {
    'city': ['New York', 'London', 'Paris', 'Tokyo', 'New York', 'Paris'],
    'price': [200, 150, 320, 250, 180, 300]
}

df = pd.DataFrame(data)
print("Original DataFrame:\n", df)

```

### Step 2: Calculate the Target Mean per Category

We group the data by the categorical feature (`city`), calculate the mean of the target variable (`price`), and convert the result into a Python dictionary for easy mapping.

```python
# Calculate the mean price for each city and convert to a dictionary
mean_price = df.groupby('city')['price'].mean().to_dict()

print("\nMapping Dictionary:")
print(mean_price) 
# Output: {'London': 150.0, 'New York': 190.0, 'Paris': 310.0, 'Tokyo': 250.0}

```

### Step 3: Map the Values to a New Feature

Finally, we map these calculated means back to a new column in our DataFrame.

```python
# Map the dictionary values to the original 'city' column
df['city_encoded'] = df['city'].map(mean_price)

# Select only the features needed for model training (dropping the raw text column)
final_training_data = df[['city_encoded', 'price']]

print("\nFinal Data for Model Training:\n", final_training_data)

```

## 4. Hands-on Assignment: The `tips` Dataset

To solidify this concept, here is the solution to the internal assignment using the `seaborn` library's `tips` dataset. We will encode the categorical `time` feature (Lunch/Dinner) based on the target variable `total_bill`.

```python
import seaborn as sns
import pandas as pd

# 1. Load the dataset
tips_df = sns.load_dataset('tips')

# 2. View the relevant columns
print(tips_df[['time', 'total_bill']].head())

# 3. Calculate the mean total_bill for each time category
time_mean_bill = tips_df.groupby('time')['total_bill'].mean().to_dict()
print("\nMean mapping:", time_mean_bill)

# 4. Map the means back to a new encoded column
tips_df['time_encoded'] = tips_df['time'].map(time_mean_bill)

# 5. Verify the transformation
print("\nTransformed DataFrame:\n", tips_df[['time', 'time_encoded', 'total_bill']].head())

```
