## 2. Cleaning the `Reviews` Column: Finding the Hidden String

The `Reviews` column should be purely numeric. However, `df_copy.info()` shows it as an `object`. This implies that at least one row contains text.

### The Problem

If we attempt to directly typecast the column using `df_copy['Reviews'].astype(int)`, Pandas will throw an error because it cannot convert a text string into an integer.

### The Solution: Finding and Removing the Anomaly

To find the exact row causing the error, we can use a boolean mask to filter out all rows where the string is *not* numeric:

```python
# Check if strings in 'Reviews' contain non-numeric characters
non_numeric_reviews = ~df_copy['Reviews'].str.isnumeric()

# View the problematic record
print(df_copy[non_numeric_reviews])

```

This reveals a single record at index `10472` where the review count is listed as **"3.0M"** instead of a pure number.

To fix this, we drop the specific row and then safely convert the entire column to an integer type:

```python
# Drop the bad record by index
df_copy.drop(df_copy.index[10472], inplace=True)

# Convert the column to integer
df_copy['Reviews'] = df_copy['Reviews'].astype(int)

```

---

## 3. Cleaning the `Size` Column: Standardizing Units

The `Size` column contains app sizes, but the data is messy. It contains string abbreviations like 'M' for Megabytes and 'k' for Kilobytes. It also contains the string phrase "Varies with device".

### The Strategy: Convert Everything to Kilobytes (k)

Our goal is to standardise all values into numerical Kilobytes and convert the column to a `float` data type.

1. **Handle "Varies with device":** We cannot convert this phrase to a number, so we will replace it with a `NaN` (Not a Number) value to be handled later during feature engineering.
2. **Convert 'M' to 'k':** If an app is 19M, it is equal to 19,000k. We need to replace the 'M' with three zeros ('000').
3. **Remove 'k':** Since our standard unit is now Kilobytes, we simply strip the 'k' character from the end of the strings.

### Implementation

```python
# Replace string phrase with NaN
df_copy['Size'] = df_copy['Size'].str.replace('Varies with device', str(np.nan))

# Convert 'M' (Megabytes) to '000' (Kilobytes)
df_copy['Size'] = df_copy['Size'].str.replace('M', '000')

# Remove the 'k' character
df_copy['Size'] = df_copy['Size'].str.replace('k', '')

# Convert the entire column to a float
df_copy['Size'] = df_copy['Size'].astype(float)

```

---

## 4. Cleaning `Installs` & `Price`: Removing Special Characters

The `Installs` column contains values like `10,000+` and `1,000,000+`. The `Price` column contains values like `$4.99`. Because of the `+`, `,`, and `$` characters, Pandas reads these columns as strings.

### The Strategy

We will iterate through a list of unwanted characters, replacing them with empty strings (`''`), and then typecast the columns to numerical formats.

```python
# List of characters to remove
chars_to_remove = ['+', ',', '$']

# Columns to clean
cols_to_clean = ['Installs', 'Price']

# Loop through columns and characters to strip text
for item in chars_to_remove:
    for col in cols_to_clean:
        df_copy[col] = df_copy[col].str.replace(item, '')

# Typecast to numeric formats
df_copy['Installs'] = df_copy['Installs'].astype(int)
df_copy['Price'] = df_copy['Price'].astype(float)

```

---

## 5. Handling Date and Time: `Last Updated`

The `Last Updated` column is currently a string (e.g., "January 7, 2018"). We need to convert this into a formal Datetime object so we can extract the individual day, month, and year components.

```python
# Convert the string column to Datetime format
df_copy['Last Updated'] = pd.to_datetime(df_copy['Last Updated'])

# Extract Date components into new columns
df_copy['Day'] = df_copy['Last Updated'].dt.day
df_copy['Month'] = df_copy['Last Updated'].dt.month
df_copy['Year'] = df_copy['Last Updated'].dt.year

```
