## 2. Handling Date and Time Variables

Machine learning models cannot process dates formatted as raw strings like "24/03/2019" or mixed time strings like "13:15 22nd March". We must extract the granular numerical components (Day, Month, Year, Hour, Minute) from these text fields.

### Processing `Date_of_Journey`

The date is formatted with forward slashes (e.g., `DD/MM/YYYY`). We can use string splitting to isolate each component.

1. **Split the String:** Use `.str.split('/')` to divide the date into three parts.
2. **Extract Components:** Assign the first element to a `Date` column, the second to `Month`, and the third to `Year`.
3. **Typecasting:** The extracted values are still strings. We must convert them to integers using `.astype(int)`.
4. **Drop Original:** The original `Date_of_Journey` column is no longer needed.

```python
# Extract Date, Month, and Year
df['Date'] = df['Date_of_Journey'].str.split('/').str[0].astype(int)
df['Month'] = df['Date_of_Journey'].str.split('/').str[1].astype(int)
df['Year'] = df['Date_of_Journey'].str.split('/').str[2].astype(int)

# Drop the original categorical column
df.drop('Date_of_Journey', axis=1, inplace=True)

```

### Processing `Arrival_Time` and `Departure_Time`

Time features often contain unwanted appended dates (e.g., "13:15 22nd March").

**Step 1: Clean the Arrival Time**
We use a lambda function to split the string by the space character and keep only the first element (the actual time).

```python
# Keep only the time portion, discarding appended dates
df['Arrival_Time'] = df['Arrival_Time'].apply(lambda x: x.split(' ')[0])

```

**Step 2: Extract Hours and Minutes**
Now that we have clean time strings (e.g., "13:15"), we split them using the colon `:` delimiter.

```python
# Extract Arrival Hour and Minute
df['Arrival_Hour'] = df['Arrival_Time'].str.split(':').str[0].astype(int)
df['Arrival_Minute'] = df['Arrival_Time'].str.split(':').str[1].astype(int)

# Extract Departure Hour and Minute
df['Departure_Hour'] = df['Departure_Time'].str.split(':').str[0].astype(int)
df['Departure_Minute'] = df['Departure_Time'].str.split(':').str[1].astype(int)

# Drop original time columns
df.drop(['Arrival_Time', 'Departure_Time'], axis=1, inplace=True)

```

## 3. Handling Categorical Variables

Categorical variables are text-based features. The method we use to convert them to numbers depends on whether the categories have an inherent order (Ordinal) or no logical order (Nominal).

### Feature Comparison Strategy

| Feature Type | Definition | Example in Dataset | Encoding Technique |
| --- | --- | --- | --- |
| **Ordinal** | Categories have a meaningful rank or order. | `Total_Stops` (0 stops < 1 stop < 2 stops) | Ordinal Encoding (Mapping) |
| **Nominal** | Categories have no inherent hierarchy. | `Airline`, `Source`, `Destination` | One-Hot Encoding |

### Ordinal Encoding: `Total_Stops`

The number of stops directly correlates with flight duration and price. Therefore, the order matters.

First, we check for missing values. If we find a `NaN` value, we fill it with the dataset's mode (the most frequent value), which is "1 stop". Next, we manually map the text labels to numerical ranks.

```python
# 1. Check and handle missing values (NaN)
print(df['Total_Stops'].isnull().sum()) 

# 2. Define the Ordinal Mapping Dictionary
stop_mapping = {
    'non-stop': 0,
    '1 stop': 1,
    '2 stops': 2,
    '3 stops': 3,
    '4 stops': 4,
    np.nan: 1  # Replacing NaN directly with the mode rank
}

# 3. Apply the mapping
df['Total_Stops'] = df['Total_Stops'].map(stop_mapping)

```

*(Technical Note: Ensure you only run the `.map()` function once. Running it twice on the same column will result in NaNs because the numerical values will no longer match the string keys in your dictionary.)*

### Nominal Encoding: `Airline`, `Source`, `Destination`

For features like `Airline` or `Source` city, there is no mathematical rank (e.g., AirAsia is not mathematically "greater" than Indigo). We use **One-Hot Encoding** to create separate binary columns for each category.

```python
from sklearn.preprocessing import OneHotEncoder

# Initialize the encoder
encoder = OneHotEncoder()

# Fit and transform the nominal columns
encoded_features = encoder.fit_transform(df[['Airline', 'Source', 'Destination']])

# Convert the sparse matrix back into a readable DataFrame
encoded_df = pd.DataFrame(encoded_features.toarray(), columns=encoder.get_feature_names_out())

# Note: In a full pipeline, you would concatenate 'encoded_df' with 'df' and drop the original text columns.

```

## 4. Dropping Redundant Features

Feature engineering is also about removing data that does not add predictive value or causes multicollinearity.

The `Route` column (e.g., "DEL → BOM → COK") provides the exact same information as the `Source`, `Destination`, and `Total_Stops` columns combined. Keeping it would feed the model duplicate information.

```python
# Drop redundant Route feature
df.drop('Route', axis=1, inplace=True)

```
