## 1. Introduction to Simple Linear Regression
**Simple Linear Regression** is a supervised learning algorithm used to predict a **dependent variable** ($y$) based on a single **independent variable** ($x$). The goal is to find a linear relationship, represented by a **best-fit line**, that minimizes the error between actual and predicted values.

### Mathematical Representation
The relationship is defined by the linear equation:
$$y = \beta_0 + \beta_1 x + \epsilon$$

Where:
* $\beta_0$ (Intercept): The value of $y$ when $x = 0$.
* $\beta_1$ (Coefficient/Slope): The change in $y$ for every unit change in $x$.
* $\epsilon$ (Error/Residual): The difference between actual and predicted values.

### Step 2: Feature Engineering (Train-Test Split)
To evaluate the model's performance on unseen data, we divide the dataset.
* **Training Set:** Used to "fit" the model (calculate $\beta_0$ and $\beta_1$).
* **Test Set:** Used to validate the model's accuracy.

| Data Type | Purpose | Size (Typical) |
| :--- | :--- | :--- |
| **X_train, y_train** | Model Training | 80% |
| **X_test, y_test** | Performance Evaluation | 20% |

### Step 3: Standardization (Feature Scaling)
Standardization transforms data to have a mean of 0 and a standard deviation of 1. This is critical for optimization algorithms like **Gradient Descent** to converge faster.

**Formula (Z-Score):**
$$z = \frac{x - \mu}{\sigma}$$

> **Crucial Pitfall: Data Leakage**
> Always use `fit_transform()` on training data but only `transform()` on test data. This ensures the model does not "peek" at the distribution of the test set during scaling.

## 4. Performance Metrics
We evaluate how well the model generalizes using the following metrics:

| Metric | Formula | Description |
| :--- | :--- | :--- |
| **Mean Squared Error (MSE)** | $\frac{1}{n} \sum (y - \hat{y})^2$ | Penalizes large errors heavily (squared units). |
| **Mean Absolute Error (MAE)** | $\frac{1}{n} \sum |y - \hat{y}|$ | Robust to outliers; same units as target. |
| **R-Squared ($R^2$)** | $1 - \frac{SS_{res}}{SS_{tot}}$ | Proportion of variance explained by the model. |

### Adjusted R-Squared
Unlike $R^2$, **Adjusted R-Squared** penalizes the addition of unnecessary independent variables that do not improve the model.
$$R^2_{adj} = 1 - \left[ \frac{(1 - R^2)(n - 1)}{n - k - 1} \right]$$
*(where $n$ = sample size, $k$ = number of predictors)*

---

## 5. Model Assumptions & Pitfalls
To ensure a Linear Regression model is valid, the following conditions must be met:

1.  **Linearity:** The relationship between $x$ and $y$ must be linear.
2.  **Homoscedasticity:** The variance of residual errors should be constant across all levels of $x$. A scatter plot of residuals vs. predictions should look uniform.
3.  **Normality of Residuals:** Residuals ($y_{actual} - y_{pred}$) should follow a **Normal Distribution**.
4.  **No Data Leakage:** Information from the test set should not influence the training process (e.g., during scaling).

### "What If" Challenge
* **What if** your model has a very high $R^2$ on training data but a very low $R^2$ on test data?
* **Answer:** This indicates **Overfitting**. The model has memorized the noise in the training data. To fix this, you might need more data, simpler features, or **Regularization** techniques like Ridge or Lasso (which we will cover in Multiple Linear Regression).
