## Logistic Regression — Key Concepts

### 1. The Linearity Assumption
Logistic regression separates YES and NO cases by drawing a **straight line** (decision boundary) through the data. If the true boundary is curved or complex, the model is **too simple** to capture it — this is called **underfitting**.

---

### 2. "But isn't logistic regression a curve?" ✓
Yes — but there are **two separate things**:
- **Sigmoid curve** → the S-shaped output that converts numbers into probabilities. This is what you see plotted.
- **Decision boundary** → the straight line underneath that actually separates the classes. This is always linear.

The curve is just an **output wrapper**. The decision-making inside is still linear.

---

### 3. "Where does the decision boundary come from?" ✓
The logistic regression equation is:

$$P(Y=1) = \frac{1}{1 + e^{-(b_0 + b_1x_1 + b_2x_2)}}$$

The inner part $b_0 + b_1x_1 + b_2x_2$ is a straight line. The decision boundary is simply where this equals **zero**:

$$b_0 + b_1x_1 + b_2x_2 = 0$$

That's the line. It was always hidden inside the sigmoid.

---

### 4. "Who chooses 0.5?" ✓
**We do** — it's not the model's decision. The model only outputs a probability. We apply a **threshold** to convert it into YES/NO. 0.5 is just the default "neutral" choice.

You can and should change it based on context:
- **Cancer detection** → lower threshold (0.3) — don't miss cases
- **Spam filter** → higher threshold (0.7) — don't block real emails

> The model learns probabilities. **You** decide what's "enough" to say YES.
