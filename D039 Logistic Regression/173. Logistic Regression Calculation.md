## Decision Boundry Derivation

Great question! Let me derive it from scratch.

---

## Start from the decision rule

We said earlier — the decision boundary is where **P = 0.5** exactly. That's the point where the model is 50/50, neither Pass nor Fail.

So set P = 0.5:

$$\frac{1}{1+e^{-z}} = 0.5$$

---

## Solve for z

Flip both sides:

$$1 + e^{-z} = \frac{1}{0.5} = 2$$

Subtract 1:

$$e^{-z} = 1$$

Take natural log on both sides:

$$-z = \log(1) = 0$$

$$\boxed{z = 0}$$

So the decision boundary is simply **wherever z = 0.**

---

## Now substitute z

We know z = b₀ + b₁x, so set it to zero:

$$b_0 + b_1 x = 0$$

Subtract b₀ from both sides:

$$b_1 x = -b_0$$

Divide both sides by b₁:

$$\boxed{x = \frac{-b_0}{b_1}}$$

That's where the formula comes from. Nothing magical — just solving a simple linear equation.

---

## Intuition check with our numbers

After epoch 3 we had b₀ = −0.0394 and b₁ = 0.1461:

$$x = \frac{-(-0.0394)}{0.1461} = \frac{0.0394}{0.1461} = 0.270 \text{ hrs}$$

Which means at x = 0.270 hrs, z = 0, and therefore P = exactly 0.5 — the tipping point between Fail and Pass.
